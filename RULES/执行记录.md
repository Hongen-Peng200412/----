### 译法与符号处理

| 中文表达或原稿位置 | 英文处理 | 含义核对与选择依据 |
|---|---|---|
| “真实的或 CryoAtom2 自动建模的”受体 | `either deposited or automatically modelled by CryoAtom2` | 使用已确认的沉积受体定义；此处说明输入种类，不增补原文没有的盲测限制 |
| 原子“身份表征” $a_i$ | `encodes the atom's attributes` | 紧接元素类型和氨基酸／核苷酸类型的例子，并保留 50 维特征；避免与 Match 的配体化学身份混淆 |
| 多视角密度通道库 | `56-channel multi-view density bank`，后文 `multi-view density bank` | 使用术语表 D05 的标准名称；56 通道张量形状原样保留，不沿用中文括号中的旧英文拼法 |
| `ligand area`、`blobs` | `ligand regions`、`candidate ligand regions (blobs)` | 保留 Find 定位后可能包含假阳性的候选属性，以及 26-连通定义 |
| 正文的 Matcher、Builder 和 PocketXmol | `Match`、`Build`、`PocketXMol`；微调后的模型 `PocketXMol-tuned` | 按术语表统一显示名称；保留原有数学函数名、参数及输入输出，不改代码接口 |
| Match 分段公式中的中文条件 | 译为 `is not a false positive`、`has ligand identity`、`is a false positive` | 保留 $(1,S_k)$ 与 $(0,\emptyset)$ 两个分支；仅调整英文条件与公式换行，仍为可编辑 Word 原生公式 |
| “以整图作为单位”及相关配体测评 | `for each full density map`；`the relevant ligands from these PDB entries` | Find 的评价单位为整图，Match／Build 的测评对象为相关配体；不把二者改成同一平均层级 |

原稿复用了密度符号 $M$：前文密度库是 $M\in\mathbb{R}^{56\times D\times H\times W}$，Build 可选引导密度写为 $M\in\mathbb{R}^{D\times H\times W}$。本轮忠实保留两种形状与“可选”条件，没有把 Build 的通用对接输入静默改成 56 通道张量，也没有替作者引入新的符号。后续若要区分这两个表示，应先明确各自指涉，再同步中文、英文及关联图注。受体表示 $(a_i,x_i)$、$p\in R^3$ 也保留原稿写法。

以下译法依据原文与全文定义确定，供作者复核；未发现需要暂停本轮的科学含义歧义。

| 原文与位置 | 采用译法 | 其他可能译法及取舍 |
|---|---|---|
