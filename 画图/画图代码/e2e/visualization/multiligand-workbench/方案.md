# 多配体交互画图工程

为 11JB、9BJJ、9LOV、9OKP、30GA、9UJF、9WUP、9LW1、9LLG 建立可继续编辑的 ChimeraX 1.10.1 会话。大型原始材料与会话保存到 `D:/AdaLigand_Visualization`。本目录保存长期程序、操作手册；冻结清单与证据保存到 `../../output/multiligand-workbench/`。本工程不重新训练、推理或选择新实验结果。

## 材料与显示

每例含实验密度、GT 与 CA2 受体及各自模拟密度、逐实例真实配体与真实区域、逐 blob 的完整 Find 候选、已有 Build 的 top-1 与原评价 best-of-50。完整 50-pose SDF 保留在磁盘。坐标保持世界 XYZ Å；地图使用原网格，区域小图只截取包围盒。每个候选保留一份物理材料，评估模式共用它。

提供 Find 全配体、Find 小分子、Find+Match 全配体、给定正确身份 Find+Build、Find+Match+Build 五种模式。预算为 50/100/200/300% 或全部。Find 小分子使用 Stage 1 的 94 PDB/821 实例范围；Build 使用 77/446 范围。各模式先按冻结规则计费，再执行“无过滤、排除假阳性、仅小分子、仅合格小分子”显示过滤。假阳性按原双向覆盖均至少 30% 的对应关系判定。过滤不退还预算、不补入候选。

## 手动调整的行为

面板控制候选 blob、关联构象、身份标签和匹配标记的对象显隐。受体、完整地图、全局真实配体与真实区域独立控制。手动显隐只报告差异，不自动纠正。改变颜色、透明度、表示方式、相机和密度阈值不改变这项提示。

清除过滤只撤销过滤的隐藏，保留当前配置中的手动隐藏。恢复预设显隐清除预测blob、构象和标注的人工例外，但保留外观。切换评估模式、CA2/GT 或预算按新配置重设预测材料的显隐；外观继续保留。切换top-1/best清除构象的人工显隐，保留blob的手动隐藏；标注开关只调整标注。保存并重新打开会话恢复实际画面、当前配置和人工例外，不重新应用默认显示。

“返回全局视角”只恢复命名视角overview；“回到本例初始总览”执行一次恢复：CA2、全配体Find+Match、100%预算、无过滤、top-1、关闭标注，显示CA2受体cartoon和全部真实配体sticks，隐藏完整地图/真实区域，再回到overview。后者清除预测材料的人工显隐，保留颜色、透明度和密度阈值；两者均为命令按钮，不是状态提示。这里的“初始”指交付的本例总览，不是后来任意另存会话的打开时刻。

Python 轻量工具负责面板、状态记录和显隐监听。显示、着色、地图处理、相机与导图均执行官方命令并留在 Log。安装后的工具不依赖 temp；保存的工作会话用相对路径引用本案例资产。

## 参考名称与可见范围

Models 中的参考配体与区域使用原实例、配体身份和沉积位置命名，如 `ref_0_ATP_A901` 与 `area_0_ATP_A901`。内部 key、模型编号和科学连接不变。多残基实例仅在短名列出首残基与其余残基数，完整组成保留在 scene.json。

真实区域默认是橙色、不透明、0.5 等值面的网格。内部 surface 是 ChimeraX 的原生子模型；初始化及 home 准备好 surface，仅关闭区域体积本身，使勾选一个 area 就能显示。初始不显示区域。五种模式均独立于全部真实配体的显隐，切换模式不自动过滤真实配体。

新初始会话关闭深度淡化；聚焦与口袋命令使用 `clip false`，返回全局或初始总览解除裁剪。旧个人会话可显式执行 upgrade：补充参考名称、准备原本关闭区域的子表面、关闭深度淡化及裁剪，保留实际配色、相机、配置和预测显隐；另存为新文件。旧示范图和作者 PPT 不因本次交互修正被覆盖。

预算内的“全部 blob”指在额度耗尽前考察到的全部候选，包括免费跳过的非目标类型及计费的假阳性；不等于原始候选全集。只有已有且属于当前模式的预测构象才显示。选定预算后再过滤，不退还或补充额度。

## 交付与验收

核对九例全部参考名称、区域颜色及子表面；在真实 GUI 勾选一个区域、执行 focus/pocket/home/overview 并保存重开。确认视角操作不添加裁剪，五种模式的预算与既有冻结评价不变。保全旧初始会话和个人版本，新增升级用例检查配色、相机、配置及预测显隐不变。

先验证 9BJJ 的五模式、预算、过滤、手动隐藏、标签、姿态和保存恢复，再验证 11JB 大案例性能，推广其余七例。每例生成 Find–Match、Build 总览及少量局部示范；两至三个互补案例装配新的可编辑候选 PPT。已有作者 PPT 与正文保留。

交互手册按聚焦、缩放、口袋、密度、配色、预算、导图、保存组织，使用已调过的具体对象与数值。准备说明和科学字段单独存放。实际原生命令、材料来源、样本与 SDF 记录连接、坐标约定、缺失结果均留证。

## 第一版图的内容

候选主图回答“同一个复合物中，区域定位与身份匹配结果怎样连接到小分子原子建模”。采用六面板图：11JB、9BJJ、9LOV 各一组全局 Find+Match 与局部完整流水线 top-1 构象。11JB 提供78实例的规模，9BJJ 提供两种小分子身份，9LOV 提供小分子与两种离子的组成。各例完整完成数直接列出，不把局部成功实例当作整个复合物全成功。

这是分子图像联图，目标宽180 mm，六个相同图像区域按两列三行对齐，最小字体不低于5 pt。ChimeraX 生成全部原生三维图像；Python 只组合导出的图片、添加标签并生成PDF，PPT保留独立图片与可编辑文字。九例另各一页，左右比较CA2与GT，依次显示全配体Find+Match、合格小分子完整流水线及一个局部。所有局部选择、预算、重原子RMSD与颜色含义保存在图注和输入索引中。
