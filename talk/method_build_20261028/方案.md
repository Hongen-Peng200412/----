# Build 内部设计候选

本方案依据作者于2026年10月28日确认的四种方向, 只重排方法图c内部。当前作者文件为5页: 第1页完整方法图, 第2页独立Build, 第3至5页为三种a/b样式。原5页保留; 新增4页插在第2页之后, 因而a/b顺延至第7至9页。

四个候选分别为整体与局部结构、简化密度接入机制、三个输出pose、含初始化与三个中间状态的去噪示意。统一保留黄色外框、标题和四项输入, 并保留原画布及c的比例。机制只说明局部条件读取、FiLM与坐标更新, 不展开完整网络。原生PPT对象承载文字、框和箭头; PyMOL从坐标渲染分子, 不用图像生成或位图拼贴构造分子。

整体结构采用9BJJ的沉积受体与ATP参考结构。其他输出采用同一9BJJ实例的冻结预测坐标, 并同步对应输入Pocket。多pose使用同一身份的三个原候选, 不附排名或性能结论。去噪帧按固定随机种子构造不同强度的坐标扰动, 保留原子身份和数目, 属于示意坐标而非模型真实采样轨迹。
