这里解释没有独立 Figure 的正文数字。每项写清服务器原文件、原字段、集合、算式和单位，不维护可执行程序或一套长期统计 JSON。

- [数据规模.md](数据规模.md)：旧划分、Find 实际训练池、Match 各筛选层级及 Build 实例数。
- [运行时间.md](运行时间.md)：Find、Match、Build 和 EMERALD-ID 分别测量的时间范围。
- [重原子数.md](重原子数.md)：present 原子数的实例等权平均。
- [EMERALD-ID身份准确率.md](EMERALD-ID身份准确率.md)：成本截尾、原查询位点、有效评分资格与精确身份正确数。
- [正文与原件的口径差异.md](正文与原件的口径差异.md)：已核实的文字与原件差异，供作者修稿时判断。

这些数字已在本轮从原件重新核算。核算脚本和中间结果仅供当次验收，不进入活动绘图代码。图表的指标、分母和重建方法仍由各 Figure 的 `trace.md` 负责；实验生产事实见 [../source/README.md](../source/README.md)。
