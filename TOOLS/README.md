# 论文项目的中性工具

这里集中可复用机制，不保存实验根、模型选择、成员资格或评价规则。各 Figure 为工具提供明确输入和显示参数。

| 子目录 | 职责 |
| --- | --- |
| `runtime/` | 固定依赖位置、运行时定位及显式模块装载 |
| `server_io/` | 只读取得明确服务器路径的原字节并校验副本 |
| `ppt/` | 中性图元、SVG、Office 容器、备注及作者显示设计的解析装配 |
| `figure_runner/` | 按每图声明运行，限制本次 temp，维护来源短指路 |
| `word/` | Markdown/Word 双向转换及格式检查 |
| `chimerax/` | 独立原生进程、会话重开及中性工作台机制 |
| `sync-to-server/` | 完整捕获、全面 Git 恢复验收及说明镜像事务 |

旧位置不留转发入口。科学共享由一个具名 Figure 拥有，其它图显式引用。
