### 译法选择及对应范围

以下译法依据原文与全文定义确定，供作者复核；未发现需要暂停本轮的科学含义歧义。

| 原文与位置 | 采用译法 | 其他可能译法及取舍 |
|---|---|---|
| Abstract、Introduction 的“真实受体”及盲测条件 | `deposited receptor structure`；盲测写 `without deposited receptor structures as input` | `ground-truth receptor` 容易混淆评价参考与输入。Methods 将真实受体定义为 PDB 沉积结构，因此按全文定义选词；不把盲测写成没有评价参考 |
| Abstract 与三阶段说明的“构象构建／三维构象” | `pose reconstruction`、`ligand pose` | `conformation` 只明确内部构型，本文重建还涉及位置和朝向。Introduction 首段同时讨论内部构象与结合位姿时保留 `conformations and binding poses` |
| Abstract、Introduction 的“明显快于” | `substantially faster` | `significantly faster` 容易暗示统计显著性检验。保留原文明确的速度优势，不额外增加防御性限定 |
| Abstract 的“高效自动化闭环” | `an efficient, fully automated workflow`，保留从密度到全原子位姿的起止对象 | `closed-loop workflow` 通常暗示反馈控制。本句描述流程贯通，采用自然英文，不增添反馈机制 |
| Introduction 的“图–上下文双重注意力”及图注“背景注意力” | `graph and context attention`、`context attention` | `background attention` 容易被理解为前景／背景区域分类。架构图标签与正文机制均指同一 PDB 其他身份的上下文，统一映射到术语 N13 |
| Introduction 的“前十次尝试” | `within the first ten attempts` | `ten poses` 会改变计费尝试预算与采样构象数的含义，因此保持 attempts；没有把摘要原本未展开的预算补成新论述 |
