# 两个病例的选择依据

本轮从已有完整来源的七个复合物中选择，阈值与当前 Stage 1 统计一致。主病例 9BJJ 能连续展示完整 map 的误报、受体上误报和真实配体附近的预测形状；9WUP 保留作备选。

## 全局候选

下表为全配体、instance-level、τ=0.3 的冻结结果。“全部预测”包含全部 `candidate_selected`，没有为展示减少候选。

| PDB | 真实实例 | CA2 预测 / TP / FP | Emap2lig-Find 预测 / TP / FP | GT 预测 / TP / FP |
| --- | ---: | ---: | ---: | ---: |
| 9BJJ | 19 | 14 / 11 / 3 | 305 / 10 / 295 | 13 / 11 / 2 |
| 9WUP | 8 | 7 / 7 / 0 | 157 / 3 / 154 | 7 / 7 / 0 |

9BJJ 的 Emap2lig-Find 有 270 个不兼容候选，其全部体素中心距离沉积受体重原子均超过 8 Å；CA2 为 0。选定远处误报为原生 blob 20，与所有真实配体区域零交集，最近受体距离为 43.4 Å。受体上误报选 blob 148，也与全部真值零交集；其 218 个体素中，108 个体素中心距离受体原子不超过 1.5 Å。

9WUP 对应远处不兼容候选为 Emap2lig-Find 146 个、CA2 0 个。展示 blob 2，最小受体距离 29.5 Å；受体上误报为 blob 139，与全部真值零交集，84/203 个体素中心位于受体原子 1.5 Å 邻域。

全局比较始终使用沉积受体作为共同位置参照，CA2 输入受体另外加载供切换。真实配体区域与 GT 条件预测是不同模型：前者是标签，后者是 Find 在沉积受体输入下的输出。

## 局部实例

| PDB 与实例 | occurrence | CA2 blob / Dice | Emap blob / Dice | GT blob / Dice |
| --- | ---: | ---: | ---: | ---: |
| 9BJJ ATP，A:902 | 1 | 3 / 0.799 | 143 / 0.439 | 0 / 0.810 |
| 9WUP HEM，A:1101 | 0 | 1 / 0.901 | 100 / 0.534 | 0 / 0.898 |

9BJJ ATP 的真实区域有 312 个体素。CA2 blob 3 含 381 个体素，真值交集 277；Emap blob 143 含 772 个体素，交集 238。Emap blob 在配体外向受体延伸：251/772（32.5%）个体素中心距受体重原子不超过 1.5 Å，CA2 为 9/381（2.4%）。两者都进入当前 τ=0.3 的实例匹配，差别体现在预测范围与受体的空间关系。

9WUP HEM 的真实区域有 451 个体素。CA2 交集 434/512，Emap 为 277/587；受体 1.5 Å 邻近体素中心分别为 7/512（1.4%）和 57/587（9.7%）。本例保留完整全局比较及局部会话，便于作者比较展示效果。

`receptor_fp` 命名视角展示完整 map 中选出的受体上误报；`local` 展示真实配体实例附近的命中 blob。两者的科学职责不同。酒红模型 #18 只标出 Emap 局部预测中距受体原子 ≤1.5 Å 的体素中心所对应的掩码，用于辅助观察；主比较仍使用未经删改的完整 blob。

准确值、每个 blob 的原始分数及坐标见 `output/stage1-global-local/{screening,prepared}`；输入与服务器来源的对应见 `source_audit.json`。这些材料完成了病例准备，正式 PPT 排布与论文叙述留待作者选定展示后落实。
