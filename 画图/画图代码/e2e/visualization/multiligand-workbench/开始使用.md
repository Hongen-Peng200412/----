# 从这里开始

你主要使用两样东西：D 盘中的案例会话，以及[交互命令速查](交互命令速查.md)。会话已经装好材料；速查告诉你怎样继续调整画面。

## 打开一个案例

1. 启动 **ChimeraX 1.10.1**。
2. 在菜单 **File → Open** 选择 `D:/AdaLigand_Visualization/9bjj/initial.cxs`。
3. 右侧或侧边会出现 **Ligand Workbench** 面板。它用来切换评估模式、预算、过滤和构象。官方 **Models** 列表用来展开材料、选择对象及勾选显隐。

其他八例位于同一根目录：`11jb`、`9lov`、`9okp`、`30ga`、`9ujf`、`9wup`、`9lw1`、`9llg`，各自打开 `initial.cxs`。每次只编辑一个案例。

面板中的 **CA2** 表示预测采用 CryoAtom2 受体，**GT** 表示采用真实沉积受体。**Find** 找出可能有配体的空间区域，每个区域称为一个 **blob**；**Match** 判断该区域中的配体身份；**Build** 生成小分子的原子构象。“合格小分子”指单残基、没有缺失原子、有机的小分子。

首次使用另一台电脑时，先按[准备与重建](准备与重建.md)安装随工程提供的小工具；本机安装后的工具保存在用户的 ChimeraX 目录，清空论文仓库 temp 不会卸载它。

## 建议你先试这五步

以 9BJJ 为例：

1. 面板选择 **Find+Match · 全配体 / CA2 / 100% / 无过滤**，看看全部预算内候选。
2. 在官方 Models 中展开 `CA2_Find_blobs`，把 `CA2_blob_0` 隐藏。面板会提示“含手动显隐调整”，不会把它自动打开。
3. 选择“排除假阳性”，再切回“无过滤”。你手动隐藏的 `CA2_blob_0` 仍然隐藏，过滤隐藏的背景候选恢复。
4. 点“恢复预设显隐”，该 blob 重新出现；你改过的颜色和角度保留。
5. 在配体下拉框选择 **A1AP0 · E:1001 · 实例 16**，点“只显示它周围 5 Å 口袋和 1.7 Å 密度”。然后查速查手册，尝试把密度范围改为 3 Å。

想回到最初交付的全局画面时，点 **回到本例初始总览**。它恢复CA2受体、真实配体和Find+Match／100%的默认显隐，受体回到cartoon、真实配体回到stick；你改过的颜色、透明度和密度阈值保留。

## 保存自己的修改

点面板的 **保存当前会话**，会在该例目录自动新建 `edit_001.cxs`、`edit_002.cxs` 等文件，避免覆盖已有版本。下次打开你保存的 `edit_...cxs`，继续编辑。

**清除过滤**只撤销过滤的影响，手动隐藏的 blob 仍隐藏。**恢复预设显隐**和**切换评估模式、CA2/GT 或预算**会取消对预测 blob、构象和标注的手动显隐，按面板选项显示。受体、地图和真实配体的显隐保持原状。颜色、透明度、表示方式、视角和密度阈值继续保留。打开自己保存的会话会恢复保存时的实际画面。

材料具体叫什么、对应哪个配体，可以查看每例的 `对象索引.csv`、`候选索引.csv` 和 `本例参数.md`。源文件和字段详见 [README](README.md)，日常调图无需先读它。

## 把修改用于论文图

第一版在[多配体交互候选图](../../../../多配体交互候选图_20261023.pptx)：第一页组合11JB、9BJJ、9LOV，其余九页逐例比较CA2与GT。每个面板是独立图片，标题和标签可编辑，双语图注在PPT备注中。

在ChimeraX调好后，先保存会话，再导出PNG，最后在PPT替换对应面板图片。若改变了预算、top-1/best或展示实例，也一起修改该页标签和图注；会话中的修改不会自动回写PPT。
