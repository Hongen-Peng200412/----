# ChimeraX常用操作速查

模型显隐主要用Models的显示勾选；颜色、卡通、Stick主要用上方Home及Actions菜单。模型号和材料身份去看各病例教程，不在这里重复登记。

## 先选对象，再改外观

Models的显示勾选是“看见它”，选择勾选是“接下来操作它”；只高亮名称不等于选择原子。下面的`sel`表示当前选中的对象，使用前先选好。操作后用`Select → Clear`清除绿色选择框。

| 想做的事 | 常用命令 | 怎样理解 |
|---|---|---|
| 卡通更透明 | `transparency sel 85 target c` | c为cartoon；百分比越大越透明，不改原子棒的透明度 |
| 原子棒恢复不透明 | `transparency sel 0 target a` | a为atoms/bonds，与卡通分开控制 |
| 切换棒状／球棍 | `style sel stick`／`style sel ball` | 也可点Home的Stick／Ball stick |
| 卡通同时保留主链原子 | `cartoon sel suppressBackboneDisplay false` | 允许N/C/O等显示；再点Atoms Show显示需要的原子 |
| 记住／返回某个取景 | `view name overall`／`view overall` | 记相机与模型位置；不恢复颜色和显隐 |

密度用Volume Viewer：眼睛控制显隐，颜色块改色，`surface/mesh`切样式，`Level`改等值面。颜色编辑器Alpha channel取0–255，越小越透明。区域掩码的阈值按病例说明保留。

密度与ligand area同时透明而看不清内部区域时，可先让area不透明，密度改为浅色mesh，再调整背景浓淡。

## 取景与保存

左键拖动旋转整体，中键拖动平移，滚轮缩放；右键功能可在Right Mouse页签选Translate。做“原图局部放大”时只平移与缩放。菜单File → Save…可分别保存session和PNG；精确导出也可用：

```chimerax
save "C:/你的保存目录/author01.cxs" includeMaps true
save "C:/你的保存目录/author01.png" width 3000
```

先把路径改成实际位置。CXS用于继续编辑，PNG用于PPT；同一视角使用同名文件，保留当前采用图片对应的源会话供后续编辑。
