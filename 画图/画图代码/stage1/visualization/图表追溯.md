## stage1-fourcase-main｜四例真实配体区域与预测的三维比较

**共享关系与本图选择。** 本图的直接生成逻辑保存在本图长期目录；其冻结来源可能同时被其他实验使用，但当前入口不转发到其他具体图目录。 本次完整入口按稳定图名 `stage1-fourcase-main` 选择图或所在共享图组。

**清空temp后的完整重建。** 从仓库根执行 `python -X utf8 -B 转换工具/ops/rebuild_figures.py --figure stage1-fourcase-main`。入口顺序运行必要的数据准备、绘图／原生渲染、场景运输和PPT装配，始终屏蔽所有旧temp读取；同一次运行产生的中间文件可以继续使用。冻结实验输入与作者原生素材只从长期目录读取，图稿、命令日志、现场读取记录、`receipt.json`和含本图的`rebuilt.pptx`统一位于新建的 `temp/figure_rebuild/<运行号>/<图名>/`。正式图形不被覆盖；作者双语备注与本条来源说明写入新候选。

直接图像生成由每个 `<pdb>_reproduce.cxc` 中的 UCSF ChimeraX 1.10.1 原生命令承担；`open_data.py` 只按固定顺序加载十二个基础模型并保存含密度的会话。`common_style.cxc/contrast_style.cxc/density_style.cxc` 管颜色、透明度和密度表示，`<pdb>_local.cxc` 管相机。`build_deck.mjs` 将真实 PNG、原生框线、连接线和图注装入七页 PPT；`page.main` 明确选择 9pqm、9uwi、9wup、9rmi，稳定图名为 `stage1-fourcase-main`。三维渲染没有一个 Matplotlib 绘图函数，应追到这些原生命令。

完整链为：

```text
冻结密度/occurrence/CIF/受体token + real/cryo/emap blobs.npz/evaluation.npz
→ base/fetch_data.py（只读下载与source_manifest）
→ base/prepare_data.py（MRC/mmCIF及交集核对）
→ output/stage1-fourcase-main/base/<pdb>/assets
→ open_data.py → <pdb>_reproduce.cxc
→ output/stage1-fourcase-main/display/<pdb>/{contrast,baseline,density}/PNG
→ build_deck.mjs → 当前PPT页
```

源文件有历史复用关系：base 的原转换与下载程序在已有文件存在时复用 `source_history/source/<pdb>`，否则读取 `base/source/<pdb>`；display 的 `open_data.py` 读取 base assets。整理时这三个 output 区均保留，不因目录名含旧版而删除仍被当前病例使用的源数组。`source_manifest.json` 保存逐件服务器路径、字节数和 SHA-256；每例 `data.json` 保存最终模型顺序、contour、坐标和交集检查，`scene_checks.json` 保存相机投影与定位框的依据，`session.cxs` 嵌入密度，可离线打开。

数组是 ZYX，原子世界坐标是 XYZ，单位 Å；源 corner origin 加半个 spacing 后写为 MRC 首体素中心。稀疏掩码裁掉外围零体素时同步调整 origin，保留非零体素与世界坐标。预测和 GT 使用二值 0.5 等值面、step 1、关闭表面平滑。每例六格共用同一相机；正文选用 contrast 风格，即绿色受体与灰色密度网格。改变相机不重新计算交集。

正文局部数值来自被展示实例的掩码交集，非 PDB 等权宏平均。例如 9PQM 的 GT／CA2／Emap Dice 是 0.816489／0.816216／0.766017；9UWI Emap precision=99/100=0.990、recall=99/330=0.300，GT recall=268/330=0.812121；9WUP GT recall=296/321=0.922118。9WUP 展示的 Emap blob 91 与目标交集为 0，是最近候选，不能据此说整个 PDB 没有预测。

9RMI GT 的交集／预测体素／GT体素是 241／397／273，所以 precision=0.607053、recall=0.882784、Dice=0.719403；CA2 为 221／558／273，对应 0.396057、0.809524、0.531889。Emap 为 28／153／273，对应 recall 0.102564、Dice 0.131455。其余准确值见每例 `data.json` 和 `display/selection_metrics.csv`。病例图不能作为总体性能估计；保留的 9WQ3、9X0X、9BJJ 风格对照是生成集合的一部分，不因正文删例而改变当前图的来源。
