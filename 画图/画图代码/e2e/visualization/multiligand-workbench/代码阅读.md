# 程序阅读与打包

先读本工程README理解材料编号，再按实际处理顺序阅读：

1. `prepare_sources.py`：从当前冻结评价提取九例；给每个候选保留五种计费号和实际构象来源。只在命令要求时调用`download.ps1`。
2. `download.ps1`：按明确清单用rsync续传；把逐案例原件硬链接到同一D盘缓存。凭据只从用户目录读取。
3. `prepare_assets.py`：将原数组写成MRC/CIF/SDF，提取原top-1和best；末尾写模型编号与原生load.cxc。
4. `chimerax_bundle/src/selection.py`：只选择当前模式、预算、过滤对应的模型key，不修改科学记录。
5. `chimerax_bundle/src/tool.py`：按钮与命令共用入口；跟踪手动显隐、执行官方命令、保存/恢复状态。`__init__.py`中的BundleAPI和ToolInstance的snapshot/delete方法是官方协议所需接口。
6. `prepare_views.py`：从scene.json写用户索引和示范CXC；不负责原子绘制。
7. `render_native.py`：在一个可见窗口逐例加载、执行CXC、导出56视图与会话；也可在完整重建的新ChimeraX进程中执行同一套官方命令。
8. `assemble.py`与`build_deck.mjs`：前者排列完整原生图片并导出PDF/SVG/PNG/TIFF，后者生成十页可编辑PPT。构象和密度操作仍在ChimeraX完成。
9. `ops/`：独立检查与官方命令传递。source_receipt检查原件与地图；check_science比较冻结计数；check_interaction_native检查显隐行为；native.py只传递REST原生命令。rebuild.py是完整重建编排，由仓库的rebuild_figures.py调用；新目录中从原件转换和原生重绘，不使用既有PNG或CXS。

## 从源码打包

从仓库根先创建 `temp/multiligand-workbench/package`，再进入本目录的 `chimerax_bundle`。下列绝对路径为本机已验证环境；换工作根时一起替换仓库前缀。

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B setup.py egg_info --egg-base 'C:/Users/15919/Desktop/论文草稿/temp/multiligand-workbench/package' build --build-base 'C:/Users/15919/Desktop/论文草稿/temp/multiligand-workbench/package/build' bdist_wheel --bdist-dir 'C:/Users/15919/Desktop/论文草稿/temp/multiligand-workbench/package/bdist' --dist-dir 'C:/Users/15919/Desktop/论文草稿/画图/画图代码/e2e/output/multiligand-workbench/package'
```

将对应版本wheel复制到D盘tools，再按准备说明安装。wheel是纯Python，ChimeraX使用自身的Qt与NumPy，不混用Anaconda的二进制扩展。安装后的源代码位于用户ChimeraX安装目录，运行不读取打包temp。

## 无窗口检查的范围

`check_interaction_native.py`可由独立ChimeraX的`runscript`执行。无窗口检查省略相机、图形和字体命令。官方会话加载器在nogui中跳过ToolInstance，因此检查分别验证CXS模型显隐与工具snapshot恢复函数；自动弹出面板、字体、真实GUI自动恢复和最终像素必须在可见窗口另外验证。
