# 端到端案例与框架示意图追溯

本文件区分真实实验图与方法示意：三个案例展示冻结预测、真实地图和沉积参考；总览和架构图表达方法关系，图示候选或装饰性结构不构成定量模型成绩；计费图表达评价判定。人工删例、裁切、调版后，同一科学实例的来源链保持有效。稳定身份优先于面板字母。

当前正文仅引用第1页9LLG与第3页30GA；第2页9BJJ及其冻结来源、双语图注和下方追溯记录保留在图集中，作为未引用案例。

## 端到端案例的共享来源

三例均使用 CryoAtom2 重建受体，公开模型名为 PocketXMol-tuned。其原始数据保存为 `e2e/output/e2e-flow/source/source/<pdb>/`，基础视图为 `e2e/output/e2e-flow/views/<pdb>/`，新版显示为 `e2e/output/e2e-flow/display/<pdb>/`；首个 `source` 是来源包根，第二个 `source` 是原包内部的逐 PDB 冻结源目录。

`e2e/visualization/e2e-flow-shared/source_prepare/fetch_data.py` 只读收集原数据，`prepare_data.py` 将原坐标和密度转为 MRC／mmCIF／SDF；`base/prepare_flow_assets.py` 从相同来源构造完整地图、全部候选 blob 和 ChimeraX 命令。`base/<pdb>_reproduce.cxc` 是基础三维视图的直接原生命令。新版 `<pdb>_global_find.cxc` 去掉全局候选排名标签，`<pdb>_global_density_same_scale.cxc` 沿同一原生相机补导完整实验地图；`draw_identities.py::draw_identities` 从精确 SMILES 生成 Match 二维身份图，`build_deck.mjs` 的逐案例循环直接装配流程页，`apply_native_crop.py` 写入非破坏裁切。后续 `e2e/calculate/e2e-accounting/build_ppt.py` 只保留既有视图并更新案例 v3 的文字／容器。

原模型结果来自服务器 `/storage/penghongen/PocketXMol/final_evaluation/end_to_end/CA2/local_cov/test/local-c1/<pdb>/<blob>/`；每例 `facts.json` 和视图 `data.json` 的 `source_paths`、`method.output_dir` 保存完整路径。`ranking.json`／`candidates.json`／`poses.sdf` 保存原自评分排名与50个候选，`scientific_input.json` 保存模型实际输入；`facts.method.top1_sample_index` 连接原首位 SDF，原评价 `pose_min_rmsd_A["1"]` 给出 RMSD。图示三个 Build 外观是同一首位姿态的受体、密度、参考叠加视图，并非三次预测或按 GT 选出的三个候选。

全身份预测来源 `/storage/penghongen/Matcher/evaluation/final_smiles/strongest-1/frozen_test.json`，小分子匹配原来源 `/storage/penghongen/Matcher/evaluation/test_smallmolecule_v1/strongest-1/train_strongest1_revised_job378587_20260920T230727/evaluation.json`；精确输入身份轴、logits、预测SMILES和匹配实例均保存在 `facts.json.prediction`。原真值、受体及地图来自 AdaLigand `Ori_Data/{parse,density,smiles_assets}/` 和 CA2 重建受体目录，具体文件由每例 `paths.json` 及来源清单保存。`source_manifest.json` 与完整地图 `source/<pdb>/source.json` 记录服务器位置、字节数及 SHA-256。

`occurrence_id` 是原真实实例编号，`source_blob_index` 是原候选编号；受体导出的 CIF 链号 `C0`、`C1` 等是 token 可视化编号，不能冒充沉积的 auth 链号。密度数组为 ZYX，元数据 `origin` 是 XYZ 体素边界；导出的 MRC 首采样点为 `origin+0.5*voxel_size`。MRC转换保留原值、逐轴spacing和世界坐标，不重分割blob。全图、受体及全部候选共用原生相机，Input地图和受体共用物理比例，局部 Find／参考共用方向和尺度。PPT只对原生PNG等比缩放和可取消裁切，不改变科学坐标。

迁移后CXC中全部175处直接 `open` 引用的资源均静态存在；前次迁移离线重核七例原生日志、相机矩阵、Å/pixel及PNG尺寸通过。2026-10-23完整验收又对当前引用的9LLG、9BJJ、30GA实际启动ChimeraX重渲染，并重绘身份卡片、装配新PPT，全部禁止读取旧temp。基础 `views/` 会话的相对MRC路径完整；七份历史 `display/<pdb>/global_session.cxs` 仍含77个旧formal绝对MRC路径，因此只作冻结留档，交互复现使用已重定向的基础CXC及新版CXC；完整入口在本次构建中重新保存global_session，再让本次显示命令打开这个新会话，绝不打开上述历史会话来补取旧图。静态清单在 `temp/figure-provenance/native-resource-audit.json`，离线重核报告在 `temp/e2e_flow_v2_20261003/`。

两份原v1输入散列基线已从临时目录保全到 `e2e/output/e2e-flow/display/provenance/`；两个 `verify_*` 默认读取此稳定留档，清理temp后仍能重新验证现有科学视图，不依赖旧临时输入。
