# 9NVS：亲手调整全景及其局部放大

本教程保留前期手动练习的命名与操作方法。前期初始与参考会话已由作者按新范围删除；练习时从当前[八份作者源会话](论文图说明.md#打开材料及最终会话)中选择一份并另存开始，不再寻找已退出的初始文件。当前采用排版是三幅整体图及五幅局部图，具体对应关系见[论文图说明](论文图说明.md)，科学原件见[来源](来源.md)。

练习中的早期a–f命名只解释操作，不决定当前PPT面板。当前正式源会话保存作者角度、显隐、配色和透明度，个人练习另存，不覆盖这些原件。

## 先认清两个面板

打开会话后，在菜单 `Tools → General → Model Panel` 找到右侧 **Models**。每行的显示勾选控制该模型是否可见；选择勾选则决定后续颜色、样式等操作作用于谁。只点亮一行的名称，不等于选中了它的原子。隐藏用显示勾选，不用 **Close**，这样材料一直留在会话里。

在 `Tools → Volume Data → Volume Viewer` 打开地图控制面板。每张地图都有名称、眼睛图标、颜色块、`Level` 数值及 `surface / mesh` 样式菜单。先按模型号确认选对了地图，再调整它；若面板太挤，可拖大面板或收起暂时不用的地图。

| 模型号 | 你会用到的材料 | 操作时怎样理解 |
|---|---|---|
| #1 | 实验密度 | 三幅全景共同的灰色背景 |
| #2、#3 | 沉积受体、CA2受体 | 两份都已加载；按你的预期，仅a显示#2，b/c默认都隐藏 |
| #5 | 全部真实ligand area | a的真实区域 |
| #7、#6 | Emap2lig、LigandSeek-CA2全部保留预测 | 分别用于b、c |
| #4 | 全部沉积配体原子 | 想看原子时再打开，当前目标可先隐藏 |
| #8–15 | 定位用配体、区域和受体邻域副本 | 本轮严格放大时先全部隐藏，避免把旧局部环境叠加进来 |

## 先完成a，再切换b/c

1. 在Models中保留 **#1、#2、#5** 的显示，关闭其他模型显示。若#1仍看不见，也检查Volume Viewer的眼睛图标。这一步建立“实验密度＋真实受体＋真实区域”的a。
2. 在Volume Viewer找到#1。先选`surface`看完整轮廓；也可试`mesh`，比较哪种更容易辨认内部区域。点击它的颜色块改为浅灰；需要透明时，颜色编辑器的 **Alpha channel** 越小越透明。`Level`可先填 **0.1595962346**，这是现有预处理密度的显示参考值。选定密度外观后，b/c及对应局部沿用它。
3. #5是真实区域的二值掩码：保留 **Level 0.5、step 1**。颜色、透明度和surface/mesh可以试，暂不改变掩码阈值或平滑。密度#1和区域#5是两类材料，不要把绿色区域网格当成实验密度。
4. 受体#2可用上方`Home`的`Cartoons → Show`显示卡通。若要单独调其颜色，先在Models选择#2，再用`Actions → Color → All Options…`，只勾`Cartoons`后选色。精确透明度的简短命令放在[常见手动命令](../常见手动命令.md)，不必在此重复学习一套。
5. 左键拖动选择整体朝向；中键拖动平移，滚轮缩放。也可用上方`Right Mouse`页签把右键设为`Translate`。这时调整整个场景，保持各材料之间的位置关系。选好a后，用`File → Save…`另存自己的`author_a.cxs`。

保持相机不动，接着只切换Models的显示勾选：

| 面板 | 打开的模型 | 其余处理 |
|---|---|---|
| a | #1、#2、#5 | 真实受体仅在这里显示 |
| b | #1、#7 | 隐藏#2、#3及其他区域 |
| c | #1、#6 | 隐藏#2、#3及其他区域 |

切换后不要再按Models的`View`、工具栏的全局适配或重新转动；直接分别另存`author_b.cxs`、`author_c.cxs`，就能保留相同朝向和尺度。若决定更改背景密度外观，三幅一起采用同一设置。

## d–f：从上面的画面直接放大

先打开自己的`author_b.cxs`。用**平移＋滚轮缩放**把误报区域i移到中央并放大，另存`author_d.cxs`。接着重新打开`author_b.cxs`，对A1B32所在区域ii做同样操作，另存`author_e.cxs`。不要打开旧局部模型#8–15，也不要重新旋转、截取密度或改变表面阈值；这样下排才是上排的简单放大。

在e的画面上，只关#7、开#6，即可得到相同局部朝向和放大倍数的f，再另存`author_f.cxs`。它对应上方c的同一空间区域。旧图所指实例为A1B32（B:1001）；#12可作为误报位置的辅助定位材料，#8可作为该配体的位置参照，正式严格放大时仍恢复上表的显示层。

如果放大后主要问题是遮挡，先保存严格版，再尝试透明度备选；保留两版供比较。框线等你确认上、下图后，再放进PPT对应位置。

## 保存供继续调整和放入论文的版本

`File → Save…`选择 **ChimeraX session**，写到本目录自己的`author_*.cxs`，保存选项中保留地图数据。再保存一份 **PNG image**，宽度可设3000像素。CXS供以后继续调，PNG供PPT排版；每次满意的视角两者同名保存即可。通用保存命令也集中在[常见手动命令](../常见手动命令.md)。
