# 训练、验证与测试规模

PDB 数表示去重后的复合物数；记录数、候选 blob 数、真实配体实例数表示不同对象。下面的数值分别从原划分与各模型的 manifest 读取，不把一个层级的数量写成另一个层级。

## 原划分与 Find 实际训练池

旧划分位于 `/storage/penghongen/AdaLigand/Ori_Data/stage1_preparation/split/{train,validation,calibration}.json`。每个文件是记录数组，记录的 `pdb_id` 是复合物标识；记录行数与去重 PDB 数为：

| 划分 | 记录行数 | 不同 PDB |
| --- | ---: | ---: |
| train | 435,187 | 13,714 |
| validation | 5,942 | 200 |
| calibration | 3,532 | 100 |

实际 Find 原训练配置使用 `/storage/penghongen/AdaLigand/Ori_Data/stage1_preparation_box_pool_3/box_pool/manifest.json` 的 `splits.train`：13,717 条 manifest 记录、13,717 个不同 PDB。原 release 的 `_load_manifest_pool_paths` 逐项保留，读取失败报错，每个 PDB 固定产生 context 请求；没有自动删去三个 PDB 的过滤分支。因此，旧 train 的 13,714 与实际池的 13,717 都有明确原件，不能互换。

`/storage/penghongen/AdaLigand/Ori_Data/stage1_preparation_box_pool_3/split/held_out.json` 有 81,922 条记录、2,497 个不同 PDB；这不是最终 179-PDB 测试集。

## 论文测试范围

`/storage/penghongen/AdaLigand/held_out/split/held_out_06_chain/test_0.json` 的 `pdb_ids` 固定 179 PDB。逐个连接 `/storage/penghongen/AdaLigand/Ori_Data/parse/<pdb>/occurrences.jsonl`，每行一个真实实例，按 `type_tag == small_molecule` 计数：全部配体 2,502 实例；其中 94 PDB 含 821 个小分子实例。真实实例编号 `candidate_id` 仅在本 PDB 内唯一。

## Match 的四个层级

原 manifest 分别在 `/storage/penghongen/Matcher/manifests/final_train_validation_shards01_06_v1/manifest.json`、`test0_real_smiles_v1/manifest.json`、`test0_cryoatom2_smiles_v1/manifest.json`。各 manifest 的 `splits` 指向原 candidates、identities JSONL，`summary.<split>.pdb_ids` 给出声明的源范围。

一行 candidate 是一个预测 blob。`candidate_selected` 表示原最终选择；`foreground_target` 表示真实前景；前景的 `(pdb_id, target_smiles)` 必须存在于 identities 的 `(pdb_id, smiles)` 才能进入支持身份范围。背景仍可用。下表单元格为“不同 PDB / 候选 blob”：

| 划分 | 声明源 PDB | 全部 | selected | usable | selected 且 usable |
| --- | ---: | ---: | ---: | ---: | ---: |
| train | 1,650 | 1,626 / 59,503 | 1,591 / 44,670 | 1,625 / 59,476 | 1,590 / 44,643 |
| validation | 200 | 200 / 7,413 | 200 / 5,554 | 200 / 7,403 | 200 / 5,544 |
| test GT | 179 | 174 / 2,251 | 169 / 1,653 | 174 / 2,249 | 169 / 1,651 |
| test CA2 | 179 | 174 / 2,407 | 164 / 1,651 | 174 / 2,405 | 164 / 1,649 |

不受身份集合支持的前景候选分别为 27、10、2、2 个。源 PDB 可以没有任何候选，所以不能把“全部候选出现的 PDB”当作源范围，也不能把 1,650 和 1,590 都描述为同一训练筛选层级。原生产过程见 [../source/Match.md](../source/Match.md)。

## Build 的实例集合

`/storage/penghongen/PocketXMol/data/summary.json` 的 `splits` 原字段 `occurrences/pdbs/objects` 分别为实例、复合物、化学对象数量；具体成员由同根 `{train,validation,calibration,test}.jsonl` 保存。

| 划分 | 实例 | PDB | 化学对象 |
| --- | ---: | ---: | ---: |
| train | 65,290 | 7,974 | 1,997 |
| validation | 781 | 118 | 125 |
| calibration | 361 | 61 | 59 |
| test | 446 | 77 | 68 |

test 的 `views.ALL/CAP10/HF10_TO5` 分别为 446/272/227。标准 Build 消融使用 446 实例；预测中心三方共同交集的 235 实例仅属于正文 Fig5 相应面板，不能用于改写 test 的规模。条件和具体评价文件见 [../source/Build.md](../source/Build.md)。
