# Overview 与 Stage 1 图文修订

本方案依据作者在 2026 年 10 月 25 日确认的讨论实施。目标是精修中英文 Overview 与 Stage 1，将整体检出能力和候选质量分析组织成两个递进的结果单元。本轮不准备三维案例；旧案例保留原 PPT 与冻结来源，从正文移出，并在本方案保留后续位置。

## 正文与术语

Overview 用两段交代输入、受体来源、密度与受体互补，以及 Find–Match–Build 的信息流。Match 以身份指派为主，简短提及过滤假阳性。架构图 a、b、c 分别对应三个阶段。

Stage 1 按测试集与评价入口、整体性能、逐 PDB 比较、误检与漏检分析、有限候选数量下的检出能力推进。严格指标定义归 Methods。正文明确说明阈值 0.5 下两种受体条件均优于 Emap2lig-Find，完整图进入补充。

指标显示名统一为 instance-level PRAUC、instance-level precision 和 instance-level recall，不新增简称。Methods 保留一对一匹配的数学定义；代码字段不改名。其他章节只机械同步同一指标名称，不扩展章节重写。密度引导默认 Build 模型在 Overview 使用 DG-PocketXMol，并与既有 PocketXMol-tuned 名称建立对应。

## 图与统计契约

新增页追加至 `画图/stage1结果.pptx`，原有页面保持。c、d沿用原模板的分辨率着色、1–4 Å色条和等比例坐标。柱图与P/R纵轴从0起，PRAUC阈值使用标准数学下标，缩减两组四面板图的留白并统一间距。统计图采用 Python 绘制，经 SVG 几何转换为可编辑的原生 PPT 文字、线条、柱、散点和路径。

| 稳定图名 | 面板内容 | 科学问题 |
|---|---|---|
| stage1-overall-performance | a、b：全配体／小分子的 Dice 与实例级 PRAUC₀.₃；c、d：CA2 对 Emap2lig 的逐 PDB 配对比较 | 联合密度与受体输入的 Find 是否提高配体区域检出表现？ |
| stage1-candidate-quality | a、b：全配体／小分子的实例级 P/R；c、d：100% 和 300% 相对候选数量下的平均检出完成度 | 优势是否同时体现在候选集合质量与排序前列的真实实例恢复？ |
| stage1-strict-threshold | a、b：全配体／小分子的实例级 PRAUC₀.₅ | 更严格匹配条件下是否保持优势？ |
| find-only-instance-completion | 原稳定图名及完整六面板曲线，新增页复现同一冻结统计后转补充 | 完整候选数量曲线和逐 PDB 异质性如何？ |

最后一项新增页使用新的稳定图名 `stage1-completion-curves`，旧 `find-only-instance-completion` 页保留，避免图名重复。

全配体为 179 PDB／2,502 实例；小分子为 94 PDB／821 实例。主性能读取 `stage1/output/stage1-main-sixpanel/v5/data/plot_data.json`；完成度读取 `e2e/output/find-build-shared/data.json` 的 `find_full` 和 `find_stage1_small`。不采用 Build 的 77／446 子集。

Dice、PRAUC、P/R 和完成度判定均沿用冻结结果。完成度新柱图按 PDB 等权求均值，同一集合内共享 10,000 次有放回抽样索引，区间取 2.5%／97.5% 分位数。完成度按排序累计首次检出；它不改用 P/R 的全局最大匹配口径。图例固定灰色 Emap2lig、蓝色 CA2、青绿色 GT。

## 后续三维案例的位置
