多配体画图：ligwork

面板负责选择评估模式、预算、过滤和构象。受体、实验密度、真实配体等参考材料在官方 Models 面板独立开关。

切换模式、受体条件、预算会按新配置设置预测显隐；颜色、表示方式、视角和密度阈值保留。清除过滤保留手动隐藏；reset 恢复预设显隐。保存、重开会话恢复实际编辑状态。

ligwork view find_match
ligwork condition CA2
ligwork budget 100
ligwork filter foreground
ligwork filter all
ligwork pose top5
ligwork pose best
ligwork labels identity on
ligwork labels correctness on
ligwork reset
ligwork focus 16
ligwork pocket 16
ligwork home
ligwork overview
ligwork save
ligwork export

模式名：find_all（全配体 Find）、find_small（全部小分子 Find）、find_match、find_build（合格小分子，给定正确配体身份）、pipeline（沿原合格小分子评价预算，显示实际 Find–Match–Build 输出）。预算：50、100、200、300、all。过滤：all、foreground、small、eligible。构象：top1、top5、best、both。五种模式不控制真实配体的显隐。

top1 是模型原评分首位；top5 是原评分前五个候选中参考 RMSD 最小者；best 是全部五十个候选中参考 RMSD 最小者；both 保持同时显示 top1 与 best。无可用参考 RMSD 的实际构象在三档均显示同一 top1，并明确标注。输入或采样失败保留 blob、预测身份及面板中的 Build 失败原因，不生成替代构象。新增显示材料不改变冻结完成数、计费或评价分母。

home 是“回到本例初始总览”按钮对应的命令。它恢复 CA2、Find+Match、100%、无过滤，显示真实配体和 CA2 受体，隐藏地图和真实区域。颜色、透明度和密度阈值保留。overview 只恢复全局视角。

focus 与 pocket 不添加裁剪；home 与 overview 解除裁剪。远处变淡时使用 lighting depthCue false；模型被前后切掉时使用 clip off。真实区域默认橙色网格，勾选 area 即可显示。

旧个人会话可执行 ligwork upgrade 补充参考名称、实际构建与 Top-5 材料，并解除淡化与裁剪；原配色、相机和既有预测显隐保留。新增材料先隐藏，切换模式或构象档位后按原预算显示；随后用 ligwork save 另存。预算内显示耗尽前考察过的 blob，包括免费跳过和假阳性；过滤不补入预算外候选。
