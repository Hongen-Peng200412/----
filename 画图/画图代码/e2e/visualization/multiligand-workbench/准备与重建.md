# 准备材料与重建

本文件用于重新准备工程。日常编辑直接打开保存的会话，使用[交互命令速查](交互命令速查.md)。所有命令从论文仓库根目录执行；下载只读服务器既有结果，不启动模型。

## 本机环境

- `D:/Anaconda/python.exe`：NumPy、mrcfile、Biopython，以及仓库固定 `.manuscript_deps/figure_runtime` 中的 RDKit。
- `D:/ChimeraX 1.10.1/bin/ChimeraX.exe`：可见工作窗口；`ChimeraX-console.exe` 可运行正式安装命令。
- MSYS2 的 rsync、sshpass、ssh：依次从 `PROJECT_MSYS_ROOT`、`MSYS2_ROOT`、`C:/msys64`、`D:/msys64` 查找。
- SSH 沿用用户私有密码文件和已固定的 known_hosts；工程不保存密码。连接和校验入口为用户级 `Invoke-ProjectSsh.ps1`。

## 1. 整理清单并续传下载

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B '画图/画图代码/e2e/visualization/multiligand-workbench/prepare_sources.py' --download
```

生成五种评估记录与明确下载清单，保存到所属 output；原始材料下载到 `D:/AdaLigand_Visualization/_server`。逐例的 `source` 用 NTFS 硬链接指向这份缓存，同一文件不重复占用磁盘。已有文件使用 rsync 续传校验；命令不删除本地或远端文件。

只需指定案例时加 `--pdb 9bjj 11jb`；完整九例工程应使用不带 `--pdb` 的命令。改变 D 盘根目录时同时对后续准备命令传 `--data-root`。

## 2. 转换为通用资产

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B '画图/画图代码/e2e/visualization/multiligand-workbench/prepare_assets.py'
```

它生成 MRC、CIF、SDF、`scene.json` 与 `load.cxc`。大地图保留原值与原采样；每个区域只保存二值掩码包围盒。参考配体仅使用沉积结构中实际存在的原子，不补原子或叠合坐标。top-1 取原 self-ranking；best 取原 `evaluation_metrics.json` 最小 RMSD，并通过 `sample_index` 连接 `sdf_index` 提取原 SDF 记录。

## 3. 安装面板

工具源码在 `chimerax_bundle/src`，随工程保存的 wheel 位于所属 output 的 `package`，D 盘 `tools` 保留安装副本。Windows 启动参数中的中文路径可能被原生程序转码，因此安装时用 D 盘 ASCII 路径。

```powershell
& 'D:/ChimeraX 1.10.1/bin/ChimeraX-console.exe' --nogui --exit --cmd 'toolshed install D:/AdaLigand_Visualization/tools/ChimeraX_LigandWorkbench-1.0.6-py3-none-any.whl noDeps true reinstall true'
```

安装后重新启动工作用 ChimeraX。工具注册 `ligwork` 命令及 **Tools → General → Ligand Workbench**。源码修改后须重新打包、安装并重启；打包入口与命令见[代码阅读](代码阅读.md)。

## 4. 生成示范命令与材料索引

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B '画图/画图代码/e2e/visualization/multiligand-workbench/prepare_views.py'
```

写出每例 `views/*.cxc`、`对象索引.csv`、`候选索引.csv`、`poses.csv`、`本例参数.md` 和根目录的 `view_index.json`。示范命令含已调过的角度、颜色、5 Å口袋、1.7 Å密度范围及本例阈值；使用它会应用相应示范配置。

## 5. 从原始资产建立初始会话

在 ChimeraX 命令栏输入：

```text
open D:/AdaLigand_Visualization/9bjj/load.cxc
open D:/AdaLigand_Visualization/9bjj/views/CA2_find_match.cxc
save D:/AdaLigand_Visualization/9bjj/initial.cxs includeMaps false
```

`load.cxc` 关闭当前模型并重新加载本例全部材料；用于重建，不用于恢复自己的修改。自己的调整另存为 `edit_...cxs`。其他案例替换为对应目录。

要依次建立九例的初始会话、全部示范CXS与56张原生图，先在可见ChimeraX命令栏输入：

```text
remotecontrol rest start port 61113 json true log true
```

然后在仓库根运行：

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B '画图/画图代码/e2e/visualization/multiligand-workbench/render_native.py'
```

程序在同一窗口中一次加载一个案例的全部材料，导完该例后再加载下一例。`exports/load_commands.html`记录加载命令，逐视图的`exports/*.commands.html`记录实际显示、导图和相机命令；`views/*.cxc`是可直接重用的显示操作。此步骤会覆盖生成的`initial.cxs`与示范导出，个人修改请用`ligwork save`另存。

## 6. 完整重建候选图

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B '转换工具/ops/rebuild_figures.py' --figure multiligand-workbench
```

从固定D盘原件重新整理九例、转换全部资产、启动独立可见ChimeraX原生重绘，再生成十页可编辑PPT及PDF/SVG/PNG/TIFF。全程屏蔽旧temp，结果与`receipt.json`写新的`temp/figure_rebuild/<运行号>/multiligand-workbench/`，当前D盘工作会话和正式PPT保持原位。C盘需约22 GB临时空间；同盘原件使用硬链接，跨盘复制。只重建一个案例可将图名改为`multiligand-workbench-9bjj`。

此入口使用已经安装的1.0.6面板。若D盘原件缺失，先完成第1步下载；它不会运行模型或重新选择姿态。

## 7. 核对科学记录与来源

```powershell
& 'D:/Anaconda/python.exe' -X utf8 -B '画图/画图代码/e2e/visualization/multiligand-workbench/ops/check_science.py'
& 'D:/Anaconda/python.exe' -X utf8 -B '画图/画图代码/e2e/visualization/multiligand-workbench/ops/source_receipt.py'
```

前者比较五种模式与原冻结完成数、检查过滤不补候选；后者比对服务器与本地的大小和 SHA-256，检查完整地图的原值抽样及坐标头。检查日志写本轮 temp，正式来源清单写所属 output。可见面板、CXS 自动恢复及图片另按执行记录中的实际验收进行，不能仅凭数字检查宣称全部完成。
