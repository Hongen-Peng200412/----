## 全局比较：只换预测，保持视角

```chimerax
hide models
show #2,4,5 models
cartoon #2
view global
```

现在是真实区域。将绿色真值换成 CA2：

```chimerax
hide #5 models
show #6 models
```

换成 Emap2lig：

```chimerax
hide #6 models
show #7 models
```

换成 GT 条件输出用 `hide #7 models`、`show #8 models`。`#5` 才是真实区域，`#8` 是 GT 受体输入下的预测。换受体参照用 `hide #2 models`、`show #3 models`、`cartoon #3`；CA2 受体只作为可选显示，不改变预测。

完整实验密度可以叠加观察：

```chimerax
volume unzone #1
volume #1 region all
show #1 models
hide #1 models
```

最后一行将它隐藏。`show` 与 `hide` 只改显隐。全局对照使用 `view global`，不要分别对两种预测执行自动 fit，否则比较时比例不同。

## 局部比较：看真实配体与完整 blob

```chimerax
hide models
show #9,10,16 models
show #9,16 atoms
view local
```

先看绿色真实区域，再比较蓝色 CA2 和橙色 Emap2lig：

```chimerax
hide #10 models
show #11 models
hide #11 models
show #12 models
```

需要更完整的受体卡通背景时：

```chimerax
show #2 models
hide #2 cartoons
cartoon (#2 & (#9 :< 12))
```

`12` 是距配体的残基邻域，单位 Å；可改为 `9` 或 `15`。重新隐藏卡通用 `hide #2 models`，灰色原子 #16 仍在。

辅助查看 Emap2lig 伸入受体的部分：

```chimerax
show #18 models
hide #18 models
```

叠加配体附近实验密度：

```chimerax
volume zone #1 nearAtoms #9 range 6 newMap false minimalBounds true
show #1 models
hide #1 models
```

`range 6` 是显示配体原子 6 Å 内的密度，修改它只改变显示范围。返回完整密度用 `volume unzone #1` 和 `volume #1 region all`。

## 全局误报的放大

```chimerax
hide models
show #14,17 models
show #17 atoms
view receptor_fp
```

这里的 #14 是与全部真值零交集的完整 Emap2lig blob。比较同一区域 CA2 的全部预测：

```chimerax
hide #14 models
show #6 models
```

视角和灰色受体原子保持一致。需要在完整 map 上突出两处选定误报：

```chimerax
hide models
show #2,7,14,15 models
cartoon #2
view global
volume #14,15 color #b51f4b transparency 0.10
```

这只突出显示两处 blob，没有删掉 #7 的其余预测。恢复橙色可用 `volume #14,15 color #D55E00 transparency 0.40`。

## 调颜色与透明度

```chimerax
volume #11 color #5975bd
volume #12 color #D55E00
volume #10 color #009E73
color #16 #7c8797
```

`#5975bd` 是颜色的十六进制值，可替换为 `blue`、`orange` 或其他色值。编号选定对象，颜色参数选外观。

两种透明度命令的数值范围不同：

```chimerax
volume #12 transparency 0.65
transparency #16 35 target a
transparency #2 50 target c
```

`volume` 使用 **0–1**：0 完全不透明，0.65 为 65% 透明。原子／卡通的 `transparency` 使用 **0–100**，`target a` 是原子，`target c` 是卡通。灰色原子更淡时减弱背景；blob 更透明时更容易看到里面的配体和受体原子。

## 调视角、大小、裁剪与恢复

```chimerax
turn y 15
turn x -10
zoom 1.15
move x 2
```

`turn` 的数字是角度；`zoom 1.15` 放大，`zoom 0.85` 缩小；`move x 2` 沿屏幕横向移动 2 Å。改变视角前可存一个自己的名字：

```chimerax
view name my_local
view local
view my_local
```

`view local`、`view global`、`view receptor_fp` 恢复相机，不重置你调过的颜色和透明度。它们也不自动换显示对象，搭配前面的 `show`、`hide` 使用。

需要切开前景时逐步试：

```chimerax
clip near 2
clip near 2
clip off
```

每次 `clip near 2` 将近裁剪面向里推进 2 Å，`clip off` 取消。裁剪适合观察，正式比较仍需对两方法采用相同裁剪设置。
