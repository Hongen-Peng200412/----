# e2e-flow-30ga

本目录是30GA流程图的独立装配入口。`build_deck.mjs`固定选择本例，调用唯一共享实现，保留既有视图、原图注编号和`@@e2e-flow-30ga`图名。完整科学输入和来源见[阶段追溯](../图表追溯.md)。

从仓库根使用bundled Node运行本文件。默认临时清单和候选位于`temp/e2e-flow-30ga/`，结构检查后的新PPT位于`画图/画图代码/e2e/output/e2e-flow-30ga/regenerated/`。可用`--build-root <仓库temp内目录>`另设构建目录；正式PPT和冻结数据保持不变。
