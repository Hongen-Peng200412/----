# Stage2 结果图

此目录从已经冻结的 Matcher 和 EMERALD-ID 测试计数绘制六张论文图，不运行模型，也不重新计算测试预测。运行 `D:\Anaconda\python.exe 画图/画图代码/stage2/plot_stage2.py`，成品写入 `画图/formal/stage2/`。`data.json` 保存绘图所需的正确数、支持数和冻结前景 F1；分数在绘图时按正确数除以支持数取得。

## 冻结数据及图的含义

- 六轴图：四个 Matcher 变体在 179-PDB `held_out_test_0` 上的 selected 候选结果。前景 F1 使用各模型在 validation 冻结的阈值；身份准确率只统计真实前景、身份受支持的 selected 候选。六轴依次为前景 F1、总体 SMILES、小分子、糖、金属离子和肽类身份准确率。真实受体和 CryoAtom2 各有一张；肽类每张只有一个样本。EMERALD-ID 只在小分子轴用单个菱形标出其已知位点结果，不给不存在的前景和其他类别指标补值。雷达径向下界是 30%，刻度已明确标注，轮廓面积不作为指标。
- strongest-1 分类折线图：横轴是测试 manifest 中该 PDB **实际提供给 Matcher 的精确 SMILES 去重数**，5、6 和大于 6 合并为 `≥5`。纵轴是对应类别 selected、真实前景、身份受支持候选的正确数除以支持数。该图的四条分类曲线不是所有真实 occurrence 的已知位点准确率；肽类只有横轴为 1 的单个观察值。
- 已知位点对照折线图：84 个 PDB 的 357 个冻结小分子真实位置，横轴是每个 PDB 的小分子精确 SMILES 去重数。各组支持数依次为 214、75、48、20。实线的分母保留全部查询点；虚线的分母仅保留至少有一个身份取得分数的查询点。某个身份失败并不使整点退出实线分母，剩余分数仍可能答对。`density_only-106` 每点均有分数，因此两种线型数值重合。

原始数字分别可核对 [完整测试集总览](../../../../Matcher/测试结果与追溯/测试结果总览/全测试集.md)、[真实受体小分子位点结果](../../../../Matcher/测试结果与追溯/测试结果总览/nxu小分子真实测试.md)、[CryoAtom2 小分子位点结果](../../../../Matcher/测试结果与追溯/测试结果总览/nxu小分子CryoAtom2测试.md)。strongest-1 横轴分组由其服务器冻结 `frozen_test.json` 的逐候选结果与对应测试 manifest 身份表只读汇总；每一类别各组的正确数与支持数加和必须与正式实验报告的分类总数相等，绘图脚本在执行时检查该等式。

## 输出

每张图输出同名 PDF、SVG、600 dpi PNG、600 dpi TIFF，以及单面板对齐检查记录。PDF 和 SVG 保留可编辑文字，PNG 用于本地 PPT 图集；PPT 每页备注是 Word 导出的图注。绘图、PPT 打包和 Word 转换不改变冻结科学产物。

`build_deck.mjs` 先用 PPT 制作工具把六张 PNG、图名批注和中文页备注封装为图集。本机 PowerPoint 无法直接导出该工具生成的 OOXML，因此 `office_compatibility.py` 只重建文件容器：图像、六个图名和原备注均原样沿用，然后用 PowerPoint 的常规保存格式生成 `画图/stage2结果图.pptx`。论文转换器已逐页读取六个图名和备注，并从此文件导出插图。
