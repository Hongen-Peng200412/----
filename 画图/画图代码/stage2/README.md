# Stage2 结果图

此目录维护 Stage2 论文图的冻结数据、原生成代码及新旧口径。当前论文默认引用 `../../stage2结果_忽视2+2例子.pptx`: 第一页为两个受体条件的六轴比较, 第二页为 strongest 按 PDB 身份数分组的结果。新版在当前保存的原生 PPT 中局部更新 F1 点及相邻线段, 保留作者的版式和手工修改。旧图 `../../stage2结果.pptx` 保留, 当前论文不引用它。

`当前口径.json` 指向当前选用的 PPT、绘图数据及统计分支, 当前为 new。`data.json` 是旧口径冻结数据; `data_忽视2+2例子.json` 是新口径绘图数据, 仅八个前景 F1 值不同。`两种口径统计.json` 保存每个模型及受体条件的旧指标、新指标、冻结阈值、源文件 SHA-256 和排除的逐候选记录。`两种口径图注.json` 保存对应双语图注; 中文六轴图注仅改变两个候选总数。排除规则是 `foreground_target and not identity_supported`, 不删除身份无支持的背景候选。

新口径的候选总数为真实受体 1,651、CryoAtom2 1,649; 身份匹配分母仍为 1,238 和 1,160, 假阳性仍为 413 和 489。身份匹配、分组结果和 EMERALD-ID 数据已经排除了这四个例子, 不重复扣除。端到端候选排序、计费尝试序列和曲线不采用此次排除规则。切换边界见 [Stage 2 双口径规则](../../../../RULES/Stage2双口径.md)。

## 冻结数据及图的含义

- 六轴图：四个 Matcher 变体在 179-PDB `held_out_test_0` 上的 selected 候选结果。新口径前景 F1 排除对应配体不可解析的两个真前景候选, 使用各模型在 validation 冻结的阈值；身份准确率只统计真实前景、身份受支持的 selected 候选。自顶端顺时针依次为总体 SMILES、小分子、糖、前景 F1、金属离子和肽类。图 4a 和 4b 分别对应真实受体与 CryoAtom2；肽类在各条件下只有一个候选，支持数写在图注而不写在图内。EMERALD-ID 仅在小分子轴用菱形标出独立真实位点上至少一个身份取得有效评分时的准确率：真实受体为 82.6%（282 个位点），CryoAtom2 为 84.0%（313 个位点）。它不提供前景 F1 或其他类别身份准确率。雷达径向下界是 20%，轮廓面积不作为指标。
- strongest-1 分类折线图：图 5a 和 5b 分别对应真实受体与 CryoAtom2。横轴是测试 manifest 中该 PDB **实际提供给 Matcher 的精确 SMILES 去重数**，五种及以上合并为 `≥5`。纵轴是对应类别 selected、真实前景、身份受支持候选的正确数除以支持数。该图不是所有真实 occurrence 的已知位点准确率；肽类只有横轴为 1 的单个观察值。

`plot_stage2.py` 保留先前六张单图的历史绘制方法；论文当前不展示其中两张小分子真实位点直接对比图，`plot_stage2_pairs.py` 也不生成它们。保留原脚本与冻结 `data.json`，便于追溯已核对的计数，不将历史图误认为本版论文结果。

原始数字分别可核对 [完整测试集总览](../../../../Matcher/测试结果与追溯/测试结果总览/全测试集.md)、[真实受体小分子位点结果](../../../../Matcher/测试结果与追溯/测试结果总览/nxu小分子真实测试.md)、[CryoAtom2 小分子位点结果](../../../../Matcher/测试结果与追溯/测试结果总览/nxu小分子CryoAtom2测试.md)。strongest-1 横轴分组由其服务器冻结 `frozen_test.json` 的逐候选结果与对应测试 manifest 身份表只读汇总；每一类别各组的正确数与支持数加和必须与正式实验报告的分类总数相等，绘图脚本在执行时检查该等式。

## 切换口径

作者要求切回旧口径时, 运行 `ops/switch_profile.py --profile old`; 恢复新口径用 `--profile new`。脚本同步两稿的两个 PPT 引用及一处候选处理句, 保留其他作者修改。旧中文图注或对应句子发生修改时, 先核对映射。旧图的英文图注已保存在映射中, 仅在切回旧口径时写入备注。随后通过稿件根目录现有的两个 Word 转换入口编译四份 Word。当前默认是 new。

## 历史生成代码与产物

运行 `D:\Anaconda\python.exe 画图/画图代码/stage2/plot_stage2_pairs.py`，在 `画图/formal/stage2/` 输出同名 PDF、SVG、600 dpi PNG、600 dpi TIFF 和面板对齐检查记录。运行 `build_editable_deck.mjs` 后，再运行 `finalize_editable_deck.py`，生成 `画图/stage2结果图_v6_可编辑.pptx`。该文件的两页分别对应图 4 和图 5；每页的 a/b 面板分别有相同图例。线条、标记和文字均为 PowerPoint 原生对象，可独立编辑，没有整页位图。每页备注保存相应中文图注，图名批注供 Markdown 转 Word 时定位。

`build_deck.mjs` 与 `office_compatibility.py` 是此前把 PNG 放入 `画图/stage2结果图_v3.pptx` 的历史实现；该版本整页是图片。v6 原生对象图集及上述印刷图文件均是历史产物, 不作为当前论文插图来源。原生成代码保持原样, 不以重跑生成代码的方式覆盖作者当前 PPT。

此前的 `论文草稿.nature.stage2.v3.docx` 和 `论文草稿.nature.stage2.v6.docx` 是历史检查稿。两份当前 Markdown 的两处 `pptfig` 定义均指向 `画图/stage2结果_忽视2+2例子.pptx`。Word 转换器会把该 PPT 页导出为图片嵌入 Word; 修改图形及图注时回到这份默认 PPT。
