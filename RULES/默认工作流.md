# 双语论文默认工作流

中文正文保存在 `论文草稿.md`，英文正文覆盖写入 `draft.md`。按作者指定的章节推进，已翻译且未被本次修改影响的英文内容保留。共享 PPT 是图形与双语图注的来源，Word 是由当前源稿编译得到的产物。

Stage 2 默认使用 `画图/stage2结果_忽视2+2例子.pptx` 的新口径。旧图及旧统计保留, 只有作者明确要求时才按 [Stage 2 双口径规则](Stage2双口径.md) 同步切换两稿, 再重新编译四份 Word。

## 稳定文件与职责

| 文件 | 内容与维护方式 |
|---|---|
| `../论文草稿.md` | 中文正文源稿，由作者与译者按确认内容共同维护 |
| `../draft.md` | 英文正文源稿，只包含已翻译内容及编译所必需的引用图定义；后续更新覆盖指定部分 |
| `../画图/*.pptx` | 共享图形、图名定位批注以及中文／英文图注；两种正文引用同一套图名 |
| `../论文草稿.nature.docx` | 中文 Nature 版，由 `md_to_word.py` 编译中文源稿 |
| `../论文草稿.operation.docx` | 中文阅读版，由 `md_to_word_operation.py` 编译中文源稿 |
| `../draft.nature.docx` | 英文 Nature 版，由 `md_to_word.py draft.md --english` 编译 |
| `../draft.operation.docx` | 英文阅读版，由 `md_to_word_operation.py draft.md --english` 编译 |
| `../references.bib` | 两稿共用的文献元数据；引用键不翻译、不重命名 |
| `执行记录.md` | 每批翻译的范围、来源版本、作者选择、核对结果和未完成范围 |
| `../temp/` | 可再生测试、快照、渲染及校验中间文件；不作为论文正文来源 |

## “翻译指定部分”的范围

作者说“翻译 Abstract”“翻译 Introduction”或指定多个章节，即授权翻译这些章节的正文及它们引用的图。图的英文化包括图注与图内文字；已经符合英文术语规则的标签只需核对。正文中的普通图片、表格、表注和图形中嵌入的文字同样在引用范围内。

正文只用 `figref` 引用某张图、而该图的 `pptfig` 定义在未译章节时，从中文源稿找到原图名和 PPT 路径，并在英文稿的合适位置加入同一图的独立定义。只加入图，不借此翻译未授权的其他章节。每个图名在一篇源稿中只定义一次；以后翻译图原属章节时可以移动已有定义，不重复插图。

若指定段落没有插图，不为补齐排版另造图。每份 Word 的图号按本稿插图顺序生成；中英初期章节覆盖范围不同，按图名核对同一图，不能依赖暂时图号建立跨语言对应。

## 每轮操作

1. 读取当前中文、英文和相关 PPT 的已保存内容，核对本次手工修改及上次记录。所有备份保存在 `temp/`，不把早先聊天中的文本当成最新源稿。
2. 按[术语表](中英术语表.md)和[翻译规则](翻译与同步规则.md)翻译指定正文；按照引用图名定位需要英文化的 PPT 页。
3. 在 PPT 备注已有中文之后添加或更新英文区。中文区保留作者内容；中文后续变化时同步对应英文区。分隔及读取的具体格式仅由[转换工具说明](../转换工具/README.md)定义。
4. 核对图内文字，包括可编辑文本和已经绘入图片的标签。标签修改不能改变数据、面板、颜色、坐标或统计含义；图形修改回到所属 PPT。
5. 覆盖更新本次英文内容，核对中英数字、公式、引用、实验条件和结论力度，详细汇报需要作者选择的译法。
6. 使用两个现有转换入口编译需要更新的 Word；英文显式使用 `--english`。检查图注语言、图号、正文引用、文献与版面，并记录本轮结果。

## Word 与手工编辑

Markdown 是正文的维护源。若作者明确要求接纳 Word 中的改动，先按转换工具说明回转到单独的 Markdown 文件，比较并纳入相应语言源稿，再同步另一稿。不能用旧 Word 覆盖当前 Markdown。

作者可在工作期间继续编辑。写入前再次检查涉及的源稿和 PPT；若它们发生变化，纳入新内容而不回退作者改动。PPT 中未保存的内容与磁盘文件不一致时，先核对正在编辑的版本；转换器编译已保存快照。目标 Word 被占用时保留完整待发布文件并汇报位置，不关闭作者窗口或丢弃未保存修改。

## 完成范围

每轮完成以“指定正文及引用图已英文化，关联中文含义一致，编译与必要检查有证据”为准。部分翻译的英文稿不混入尚未翻译的中文章节；未译章节只在执行记录列出。没有作者的进一步指令，不自动启动下一批翻译。
