# 9WUP：透明卡通、口袋侧链和碰撞原子

打开[初始材料_9WUP.cxs](初始材料_9WUP.cxs)。完整受体、整张实验密度、参考FAD及原来的三种Top-1构象都已加载。初始只显示受体和参考配体，保留ChimeraX自动样式；请从这里亲手调整。病例为 **FAD A:1103，occurrence 2**，来源及原指标见[来源.md](来源.md)。

可另开[参考显示_9WUP.cxs](参考显示_9WUP.cxs)看看尝试效果：95%透明卡通、口袋细棒、参考与Emap构象、灰色密度网格和原碰撞标记。这是可继续调整的示范，尚非论文定稿，不影响初始材料。

## 先选一种预测，搭好共同环境

从`Tools → General → Model Panel`打开Models。显示勾选控制是否可见，最右侧选择勾选控制菜单操作作用于谁。名称高亮与原子选择不同；每次改颜色、卡通或原子样式前，检查当前选择，避免误改所有模型。

| 模型号 | 材料 | 使用方法 |
|---|---|---|
| #1 | GT完整受体 | 三幅图共用的卡通和口袋侧链 |
| #2 | 实验密度 | 已嵌入会话，默认隐藏，可随时打开 |
| #3 | 参考FAD | 三幅图共用 |
| #4 | PocketXMol原Top-1 | g |
| #5 | DG-PocketXMol原Top-1 | h |
| #6 | Emap2lig原Top-1 | i |
| #7 | 原14对碰撞的红色虚线 | 只在显示#6时打开；#4/#5原碰撞数为0 |

先显示#1、#3、#6，隐藏#4/#5/#7。以Emap构象先调环境，容易观察怎样保留碰撞位置。完成环境后，换另外两个构象只切显示勾选，保持相机、受体和密度设置不动。

## 透明卡通与侧链

1. 在Models选择#1。上方`Home`中，点`Atoms → Hide`隐藏受体原子，再点`Cartoons → Show`保留完整卡通。先隐藏原子可避免全受体棒状结构挡住配体。
2. 打开`Actions → Color → All Options…`，在`Coloring applies to`里只勾`Cartoons`，给受体一个浅色。若要精确控制卡通透明度，可在#1仍被选择时使用[常见手动命令](../常见手动命令.md)中的卡通透明度命令。透明度越高，卡通越淡；原子棒状结构可以保持不透明。
3. 从`Tools → Depiction → Basic Actions`打开Basic Actions。上方`user-defined names`中有 **pocket、clashRec、clashLig** 三行。`pocket`是参考与三种预测共同的5 Å显示邻域，按完整残基选择，三幅图共用。点击`pocket`名称选中它，再用`Actions → Atoms/Bonds → Show Side Chain/Base`显示侧链及连接卡通的CA，随后点`Home → Styles → Stick`。可试`Ball stick`，看哪个更清楚。不要在三幅图中分别重新选不同邻域。
4. 清除选择后，先转动整个场景找合适朝向，再用平移和滚轮缩放调构图。这样卡通交代环境，近处侧链说明口袋，FAD仍是视觉重点。只选择`pocket`不会改变其显示，必须再按显示或样式按钮；Basic Actions的`Atom`栏也有直接显示／隐藏按钮。

## 密度与共同环境

在`Tools → Volume Data → Volume Viewer`找到#2，打开眼睛，选择`mesh`并把颜色改为灰色。`Level`先设 **0.2613414526**，`step`设1。如果整张密度挡住口袋，可用上方`Map`页签的`Zone`工具：先仅选择参考FAD #3，再把显示密度限制到参考附近，三幅图沿用同一范围。它改变显示范围，不改变原图数值。想先看清受体时也可暂时关掉密度，最后再打开。

完成卡通、侧链、密度和共同取景后，先用`File → Save…`保存自己的`environment.cxs`。这份共同环境不显示#7，也不添加红球或额外的主链碰撞原子。下面的g/h/i每次都从它重新打开，防止前一幅的局部样式留到后一幅。

## 把原碰撞标记显示清楚（只用于i）

从`environment.cxs`开始，显示#6，隐藏#4/#5。碰撞有主链原子参与，因此还需做一次小设置：在命令栏输入 `cartoon #1 suppressBackboneDisplay false`，允许卡通与N/C/O等主链原子同时显示。这只是显示开关，不会重判碰撞。

在Basic Actions点击 **clashRec** 名称，然后用`Home → Atoms → Show`显示参与碰撞的10个受体原子。若希望更突出，可点`Styles → Sphere`或`Ball stick`，再通过`Actions → Color`设为红色。`clashLig`同理选中涉及碰撞的8个配体原子；是否额外标红由你决定，配体整体仍可保留方法色。操作后从`Select → Clear`清除选择，绿色选择边框就会消失。

最后在Models打开#7，显示原14对碰撞的红色虚线。虚线连接的就是保存的原碰撞端点，不需要点击“Find Clashes”重新检测。**14是原子对数，不是红色原子数量。** 完成后单独另存i；其余两幅从未加碰撞标记的共同环境开始。

## 保存三个最终视角

分别重新打开`environment.cxs`：g只显示预测#4，h只显示预测#5；i显示预测#6，再按上一节加入#7及碰撞原子。参考#3、受体#1和密度#2共用。不对每个预测分别按`View`或重新适配，以免造成不同的尺度。三种配体颜色可先沿用论文：橙／蓝／紫，参考青绿、密度灰、碰撞红。

每幅满意后用`File → Save…`分别保存同名CXS与PNG，例如`author_g.cxs`／`author_g.png`。选择session格式时保留地图数据，PNG可设宽3000。通用的显隐、选择及保存要点见[常见手动命令](../常见手动命令.md)。
