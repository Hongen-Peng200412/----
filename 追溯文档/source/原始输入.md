## 读取哪些原件

一个 `pdb_id` 对应一个复合物，统一小写。`candidate_id` 是该 PDB 内的真实配体实例编号，不能当作预测 blob 编号；连接实例必须同时保留 PDB。

| 原件 | 一个文件表示什么 | 当前用途 |
| --- | --- | --- |
| `raw/pair_list.jsonl` | 每行一个 EMDB–PDB 样本对及分辨率来源 | 当前病例、图中分辨率和样本身份 |
| `raw/rcsb_mmcif/<pdb>.cif`、`raw/emdb_maps/emd_<id>.map.gz` | 原沉积结构、原始压缩实验图 | 真值身份及官方 Emap2lig 输入 |
| `parse/<pdb>/occurrences.jsonl` | PDB 内每个共价连通配体实例；含 `candidate_id/type_tag/object_key/components` | 小分子范围、auth 链/残基、实例身份 |
| `parse/<pdb>/ligand_coords.npz` | 按真实实例和模板原子名对齐的世界坐标与 `present_<id>` | 真实配体坐标；重原子统计取 present 布尔值 |
| `parse/<pdb>/receptor_tokens.npz` | 沉积受体原子、连接和特征 | GT 受体与碰撞核算 |
| `density/<pdb>/{exp.npy,exp.npz}` | 实验密度数组与几何/原图来源元数据 | 当前全部真实密度视图 |
| `density/<pdb>/{sim.npy,sim.npz}` | 沉积受体在同一实验网格的模拟密度 | GT Find 的受体条件 |
| `density/<pdb>/ligand_area.npz` | 每实例的稀疏 ZYX 掩码和 `grid_shape_zyx` | 小分子语义并集 Dice；不能用截图还原掩码 |
| `smiles_assets/SMILE_coords/v1/<pdb>.npz`、`ligand_objects/CCD_*.npz` | 对齐的真实重原子和化学模板 | 分子身份、键与坐标供应；模板不是预测姿态 |

数组为 ZYX（必要时另有前置通道轴），世界坐标为 XYZ、Å。`origin` 是网格边界，体素中心为 `origin+(index+0.5)*voxel_size`；不能把世界坐标重对齐后再宣称同一位置。`exp.npz::source_map_sha256` 指上游原地图，不是 `exp.npy` 文件的 SHA；原字节校验必须使用 `exp.npy` 自身散列。
