# 补充分析须同时适合独立阅读与移入正文

Type: decision
Date: 2026-10-12
Tags: manuscript, supplementary-information, bilingual-writing

## Context

作者审阅端到端实例完成度补充分析后，要求补充材料与正文能够复用完全相同的科学内容，并在写作前规划必要定义、证据及上下文衔接。

## Memory

当前正式规则保存在 [补充材料与正文之间的内容复用](../../../RULES/默认工作流.md#补充材料与正文之间的内容复用)。补充分析须自成一体；原文不变地移入对应正文位置时，也须流畅、充分且无冗余。规则同时适用于中英文。

实例完成度小节保留作者从 top-k success 到 ligand completion ratio 的讲述：自变量由绝对尝试次数转为 $\rho=t/N$，因变量由二元成功转为 $f(t)/N$。翻译必须保留这一概念递进，不以实现层面的整数预算公式取代作者的行文。作者已明确拒绝本轮前三项中文改写建议，当前只补充占位数字并依据该原文翻译。

## When To Use

起草、审阅、修改或翻译补充分析，以及将补充分析移入正文时。保留作者现有叙述，按当次授权范围修改或翻译；正文空标题不自动填写。
