# 端到端计算图、表与正文数值

本文件覆盖两张实例完成度图、正文两张完成度表、两张补充 top-k success 图，以及给定正确身份的 Find–Build 柱状图和完整曲线。图名或表格标识是追溯键，自动图号和人工调整后的面板位置不作为身份键。

## 范围与共同定义

| 科学范围 | 完整分母 | 成功对象 |
|---|---|---|
| 全配体定位与身份 | 179 个 PDB、2,502 个实例 | Find 命中且 Match 身份正确 |
| 单残基完整有机小分子 | 77 个 PDB、446 个实例 | Find 命中、Match 正确且 Build 达到姿态阈值 |
| 给定正确身份的 Find–Build | 相同 77 个 PDB、446 个实例 | Find 命中且 Build 达到姿态阈值；不要求真实 Match 成功 |

实例完成度是在每个 PDB 内，以成功的不同真实实例数除以该 PDB 的全部合格实例数 N；相对预算 ρ 允许 `floor(ρN)` 次计费尝试，100%／300% 分别为 N／3N 次。均值为 PDB 等权宏平均，中位数使用同一完整 PDB 轴。零候选、未命中、身份错误和姿态失败保留分母，重复命中同一实例只在最早成功时增加一次完成数。

top-k success 则在每个 PDB 的前 K 次计费尝试中，只要有一次成功就将整个 PDB 判成功。它的分母是 PDB 数，不能与实例完成度互换。`source_blob_index` 是零基原 blob 编号，`matched_occurrence_id` 是原真实实例编号，`raw_rank` 是包含免费跳过的原候选顺序，`attempt_index` 是计费顺序或 `null`；四者不能混用。距离单位均为 Å，姿态阈值严格 `<2`／`<3`，无有效距离不判成功。

候选顺序沿冻结 selected 段优先，各段内按 `source_probability_mean` 降序、原 blob 编号升序破并列。PPT 与 Markdown 的两个来源副本由下列受管理记录同步。

**清空temp后的完整重建。** 从仓库根执行 `python -X utf8 -B 转换工具/ops/rebuild_figures.py --figure supp-find-correct-match-build`。入口顺序运行必要的数据准备、绘图／原生渲染、场景运输和PPT装配，始终屏蔽所有旧temp读取；同一次运行产生的中间文件可以继续使用。冻结实验输入与作者原生素材只从长期目录读取，图稿、命令日志、现场读取记录、`receipt.json`和含本图的`rebuilt.pptx`统一位于新建的 `temp/figure_rebuild/<运行号>/<图名>/`。正式图形不被覆盖；作者双语备注与本条来源说明写入新候选。


**载体与直接函数。** 中英文补充材料引用 `画图/E2E结果.pptx` 同名十二面板页。`e2e/calculate/supp-find-correct-match-build/plot.py::main` 的 `03_assume_matched` 分支选择十二个 `assume` 面板，调用 `completion_plot.py::draw_panel`；`svg_shapes.py → assemble.mjs` 装配原生PPT。它与正文柱状图读取同一 `data.json`，不引入第二套计数。

每种方法四个面板，依次Emap2lig、LigandSeek-CA2、LigandSeek-GT；每组上行top-1、下行best-of-50，左列严格`<2 Å`、右列`<3 Å`。全部面板均为77PDB／446实例。完整`curve`保存精确Fraction事件及右连续阶梯，`distributions`保存固定预算下完整PDB分布；小提琴只描摹分布，散点保留每PDB值。背景与范围外前景的计费、正确SMILES、原始姿态排名及失败分母与柱状图记录一致。

三域原始`completion.json`由AdaLigand既有`ligandseek_pipeline.completion.make_panel`生成；共享`assemble_data.py`直接继承这些原24个面板，再追加Find-only视图和配对RMSD，不重算本图事件。原始服务器目录、配置、散列及实际release沿补充归档同名`metadata/pipeline/`、`provenance/`、`reference_logs/`追溯。300%为展示截点，`all_candidates_final`保留全部候选用尽后的结局。正文100%／300%柱高与曲线对应预算的宏平均一致。
