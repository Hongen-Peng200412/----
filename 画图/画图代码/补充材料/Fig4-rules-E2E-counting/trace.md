# 补充Fig4的计费定义与流程节点

本图`e2e-accounting-rules-draft`是评价规则示意, 不展示新的实验观测. 正式作者页为[E2E评价计费规则.pptx](../../../PPT/E2E评价计费规则.pptx). display.json逐层保留作者当前节点、箭头、文字、主题与画布; build.py只装配本图, 不访问服务器科学文件.

## a: 全配体定位与身份

按Find原候选顺序逐个尝试, 每个候选都计费一次. 候选没有真实配体归属时失败并继续; 有真实配体归属时, Match在该PDB完整身份集合中给出原argmax答案, 精确身份正确才记成功. 同一真实实例只能贡献一次完成, 完整PDB目标集合不因没检出、没支持身份或失败而缩小. 全配体179-PDB/2502实例对应正文Fig6的完整范围, 此图不读取这份清单计算统计.

## b: 合格小分子的完整Find-Match-Build

合格目标是单残基、相对模板无缺失原子的有机小分子, 实际范围为77-PDB/446实例. 背景、非小分子真实前景、真实小分子但不合格、合格小分子四类不能仅凭Match预测标签混在一起.

| 真实范围 | 原全身份Match回答 | 图中动作 |
| --- | --- | --- |
| 背景 | 任意答案 | +1, 失败并继续 |
| 非小分子前景 | 预测为非小分子 | 免费跳过 |
| 非小分子前景 | 预测为小分子 | +1, 继续 |
| 不合格真实小分子 | 精确身份正确 | 免费跳过 |
| 不合格真实小分子 | 精确身份错误 | +1, 继续 |
| 合格真实小分子 | 精确身份错误, 包括预测为非小分子 | +1, 继续 |
| 合格真实小分子 | 精确身份正确 | 同一次候选计费+1, 进入Build; 原模型排名姿态达到严格RMSD阈值才记成功 |

Build不会对同一次候选额外再收一次费. 输入失败、无有效姿态、RMSD未严格过阈值都保留失败事实; 不填0 RMSD, 不从真实目标分母移除. Top1、Top5、best-of-50分别是原模型排名前1、5、50构象中的最低重原子RMSD, Match身份不会根据RMSD重新选择. `+1`表达一次计费尝试, 不表示一个新真实实例; 重复候选计费, 成功实例去重.
