# 交互命令速查

在 ChimeraX 底部 **Command** 栏输入。以下以 **9BJJ** 为例；所有案例都使用相同的受体与地图编号。

| 写法 | 具体材料 |
|---|---|
| `#1.1`、`#1.2` | GT、CA2 受体 |
| `#2.1`、`#2.2`、`#2.3` | 实验密度、GT 受体模拟密度、CA2 受体模拟密度 |
| `#3.17` | 9BJJ 的真实 A1AP0，实例 16；实例编号加 1 是模型编号末位 |
| `#10.1`、`#11.1` | CA2、GT 的 blob 0 |
| `#20`、`#21` | CA2、GT 的全部构象；在 Models 中展开可选单个构象 |

其他配体的准确编号查该例 `对象索引.csv`，或直接在面板的配体下拉框中选择。Models 中 `ref_0_ATP_A901` 表示真实实例0、ATP、原PDB的A链901号；对应区域名为 `area_0_ATP_A901`。这些名称不改变模型编号。

## 1. 看哪一套结果

```text
ligwork view find_match
ligwork condition CA2
ligwork budget 100
```

Find 找空间区域（blob），Match 判配体身份，Build 生成原子构象。模式：`find_all`=全配体 Find；`find_small`=全部小分子 Find；`find_match`=全配体 Find+Match；`find_build`=Find+Build 合格小分子（给定正确配体）；`pipeline`=实际 Find+Match+Build 合格小分子。后两种只评价单残基、无缺失原子、有机的小分子；“给定正确配体”指给定身份，构象仍由模型预测。

初始显示全部真实配体，**五种模式均不控制真实配体的显隐**。例如切换到合格小分子模式，MG等真实离子仍保留作参考；需要时在 Models 中单独关闭。

条件可改成 `GT`；预算可改成 `50`、`200`、`300` 或 `all`。100% 的尝试上限等于所评价的真实实例数：全配体模式用全部配体数，小分子 Find 用全部小分子数，两个 Build 模式用合格小分子数。9BJJ 分别为 19、11、11；50% 向下取整为 9、5、5 次。候选用尽时，实际尝试可少于上限。

切换模式、条件或预算会**取消对预测 blob、构象和标注的手动显隐**，按新选项显示；颜色与视角保留。受体、地图和真实配体的显隐保持原状。**CA2/GT 指预测使用的受体条件**；参考受体和地图在 Models 中独立开关。

## 2. 过滤、标注与构象

无过滤且没有手动隐藏时，画面包含**预算耗尽前考察过的全部 blob**。其中包括按原记录 `continue` 免费跳过的非目标类型，也包括扣除尝试额度的假阳性。它不等于原始 blob 全集；只有 `budget all` 才纳入全部候选。构象仅显示已有、且属于当前模式的预测；前三种模式不显示 Build 构象。例如9BJJ／CA2／Find+Build／100%包含blob 0–10，其中blob 10是假阳性，仍显示；blob 11起超出本档预算。

```text
ligwork filter foreground
ligwork filter small
ligwork filter eligible
ligwork filter all
ligwork labels identity on
ligwork labels correctness on
ligwork pose best
```

过滤依次表示排除没有真实配体对应的 blob、仅小分子、仅合格小分子、清除过滤；同一时刻选一档。过滤按命中的真实实例分类，只改画面，不补入预算外候选；清除过滤保留你的手动隐藏。标注用 `off` 关闭。构象用 `top1` 看模型首选，`best` 看同一输入的 50 个生成构象中 RMSD 最小者，`both` 同时看两者。best 用到真实构象，只作回顾性比较。

切换构象档位会重新显示该档构象，取消对构象的手动显隐；你对 blob 的手动隐藏仍保留。

```text
ligwork reset
```

恢复当前面板选项对应的预测显隐，清除人工显隐调整，保留外观。受体、地图和真实配体不会被这个命令重设。

## 3. 聚焦与放大

```text
ligwork focus 16
zoom 2
zoom 0.8
```

聚焦 9BJJ 的实例 16，并把旋转中心移到那里。`2` 放大两倍，`0.8` 缩为当前的 80%；可用 `1.25` 小幅放大。在 Models 中选定另一个分子后，也可用 `view sel clip false` 聚焦、`cofr sel` 设置旋转中心。`clip false` 避免用配体大小裁掉其他材料。

```text
ligwork overview
```

返回初始全局视角；这条命令只改视角，不恢复刚才隐藏的材料。

```text
ligwork home
```

对应面板的 **回到本例初始总览**。恢复 CA2／Find+Match／100%／无过滤、真实配体和CA2受体，并返回全局视角；受体恢复cartoon，真实配体恢复stick，地图及真实区域隐藏。取消预测材料的手动显隐，但保留颜色、透明度和密度阈值。这里“初始”指本工程交付的总览，不是你另存的edit会话。

## 4. 只看配体周围的口袋与密度

```text
ligwork pocket 16
```

显示该配体周围 **5 Å** 内的完整受体残基与 **1.7 Å** 范围内的实验密度。想扩大范围，可直接输入：

```text
hide #1 atoms
show #1.2 & (#3.17 :<8) atoms
volume zone #2.1 nearAtoms #3.17 range 3 newMap false minimalBounds true
```

`8` 是口袋残基范围，`3` 是密度范围，单位均为 Å；二者可以分别改变。上述 `#1.2` 是 CA2 受体，**看 GT 时改成 `#1.1`**。显示范围改变后，原始密度数值不变。

```text
ligwork unzone
hide #1 atoms
cartoon #1.2
```

恢复完整实验地图，并把 CA2 受体恢复为 cartoon；**看 GT 时将最后一条改为 `cartoon #1.1`**。想隐藏地图，输入 `hide #2.1 models`。

## 5. 密度怎样看得清楚

9BJJ 的实验密度起始阈值是 **0.0210956**。较低的 `0.0169` 会显示更多密度，较高的 `0.0253` 会收紧等值面。

```text
volume #2.1 style mesh level 0.0210956 step 1
volume #2.1 meshLighting false
color #2.1 #596773
transparency #2.1 0 target s
```

这是初版局部图的深灰网格设置，`0`表示网格不透明。想换一种表示方式，可任选下面一种：

```text
volume #2.1 style surface
transparency #2.1 60 target s
volume #2.1 style image
```

前两条切成透明60%的等值面；最后一条切成体绘制。体绘制的颜色与不透明度还可在官方 **Volume Viewer** 中拖动控制点调整。想保留精细几何，局部用 `step 1`；大型总览可用 `step 2` 提高速度，原图仍保存在磁盘。

其他案例及两张模拟密度的起始阈值查 `本例参数.md`，不要直接套用 9BJJ 实验密度数值。

## 6. 显隐、配色、透明度与表示方式

展开 Reference_regions 后，直接勾选所需 `area_...` 即出现橙色网格；不用展开内部的 surface。它是真实配体区域的0/1掩码，不是实验密度，固定使用 `level 0.5`。例如显示9BJJ的ATP实例0并改为表面：

```text
show #4.1 models
volume #4.1 style surface level 0.5
transparency #4.1 50 target s
```

恢复初始网格用 `volume #4.1 style mesh`，再用 `transparency #4.1 0 target s`；默认颜色为 `color #4.1 #e69f00`。

Models 列表太矮时，可拖动它与其他面板之间的分隔线。也可用 `ui tool hide "Ligand Workbench"` 暂时收起本面板，腾出空间展开材料；输入 `ligwork show` 重新显示面板，当前选项保留。

```text
hide #10.1 models
show #10.1 models
color #10.1 #009e73
transparency #10.1 25 target s
color #3.17 #e69f00
style #3.17 stick
size #3.17 stickRadius 0.16
transparency #1.2 20 target c
surface #1.2
hide #1.2 surfaces
```

前两条只操作一个 blob；关闭整个 `#10` 会隐藏整组 CA2 blob。上面的25%、20%和0.16 Å分别是初版blob透明度、受体cartoon透明度和参考配体棒半径；将25改成70会让blob更淡，将0.16改成0.25会加粗配体。局部图的预测棒半径为0.18 Å，受体棒半径为0.08 Å，按相同`size`写法修改对应模型即可。

透明度 `0` 为不透明，`100` 为全透明；`s` 指表面，`c` 指 cartoon。配体可把 `stick` 改为 `sphere` 或 `ball`。选择颜色也可使用官方 Actions 菜单。每张初版图的完整命令另存该例`views/*.cxc`，日常可只取需要的一条调整。

## 7. 远处变淡、模型缺块时

```text
lighting depthCue false
clip off
```

第一条关闭远处向背景色淡化的效果，第二条解除前后裁剪；两条都不改变模型坐标或你的颜色、显隐和视角。新初始会话默认已关闭淡化；聚焦与口袋不添加裁剪。若要先返回旧会话的全局视角，先执行 `ligwork overview`，再执行上面两条。

如果整个模型仍不见，先检查 Models 的该模型及其父组是否勾选；如果只有密度局限在口袋，使用 `ligwork unzone` 恢复完整实验图。这两种情况分别是显隐和局部密度范围，不由淡化开关控制。

## 8. 保存视角、会话与图片

```text
view name my_local_01
view my_local_01
ligwork save
ligwork export
```

前两条保存／返回一个视角；命名视角不记录对象显隐或颜色。后两条把完整工作状态另存为新的 `.cxs`，或导出 2400×1800 的 PNG，保存位置会显示在 Log。地图保持在案例的 `assets/maps` 中，会话引用它们；保留整个案例目录即可继续使用。

要指定图片文件名与尺寸：

```text
save D:/AdaLigand_Visualization/9bjj/exports/my_local_01.png width 2400 height 1800 supersample 3
```
