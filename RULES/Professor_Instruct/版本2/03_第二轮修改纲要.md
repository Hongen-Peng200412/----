# 第二轮论文修改纲要

六段录音的自动转录与分节整理已完成，共形成 42 条建议、回应与评价。本纲要是后续修改的讨论底稿，尚未实施。论文正文、图表与正式来源保持原样；最终取舍由作者与导师决定。

建议先采纳导师反复强调的主线：让读者迅速理解方法解决什么问题，再用精简的定量结果与真实案例建立证据。作者在指标指涉、对照保留和样本完整性上的理由同样应进入决策。以尽量吸收导师意见为工作方向，不用机械的“70%”比例替代逐项判断。

依据与上下文见 [42 条分节建议与评价](02_分节建议与评价.md)；时间定位与识别疑点见 [录音底稿](01_录音转录与来源索引.md)。底稿为自动识别，未经全量人工听审；有争议的原意应回到标注时间裁定。

## 第一优先级：固定科学口径与主张

1. **明确方法能力。** Find、Match 支持的对象，默认 Build 已验证的对象，以及可插拔接口分别写清。候选身份是外部输入；密度经 CryoAtom2 得到受体的路径应可见。接口可扩展不能替代全类别构象重建的实验证据。（F01、F02、F05）
2. **固定样本单位与分母。** 测试集 179 个 map／PDB、2,502 个配体实例，与 Build 的 77 个 PDB、446 个合格小分子子集分开介绍。blob、配体实例、不同 SMILES 身份、真实前景与预测前景不能互换。（R01、M04、M05）
3. **保留两种受体条件。** GT 与 CryoAtom2 重建受体可以紧凑呈现，不因合图而混合样本或取消一种条件。阈值 0.5 与完整曲线进入补充后仍完整报告。（S02、S05、M08）
4. **统一 Build 机制表述。** 密度参与生成过程；不是先用原版完成 docking 后再 refine。兼容权重继承、新模块初始化与后续训练在 Methods 中如实说明。（B01、B02）
5. **核对摘要与引言数字的条件。** 摘要 62.8% 对应 CA2、300% 尝试预算、best-of-50、RMSD <3 Å；引言在“仅 CA2 盲测”叙述中引用的 1.55→1.14 Å，在 Stage 3 对应 GT 与 Envelope pocket，应调整对应表述。这是整理者核对原稿的发现，不是导师录音指示。（G03）

Stage 2 当前冻结口径尤其需要保持：身份准确率分母 GT 1,238／CA2 1,160；前景 F1 总候选 1,651／1,649；EMERALD-ID 有效返回分母 282／313，来自单独的真实小分子位点查询。不能把它们并列后默认为完全等条件的同一组 blob。具体版本以 [计算追溯](../../画图/画图代码/stage2/calculate/图表追溯.md) 为准。

以下结构结合录音与 [辅助提纲](outline.docx) 提出。运行时间和消融目录主要由提纲支持，不能冒充录音已逐段批准。标题先确定科学问题，再按最终结果写成准确结论。

| 候选小节 | 要回答的问题 | 需要保留的现有证据 | 主要调整 |
|---|---|---|---|
| Overview of LigandSeek | 输入如何经 Find–Match–Build 得到配体模型？ | 密度与受体互补、候选身份输入、阶段间传递、默认 Build | 定义与网络细节移入 Methods；评测介绍移到相应结果（O01） |
| 配体密度的识别与分割 | 能否在全图可靠找到配体区域，较对照改善在哪里？ | 两种受体、全配体／小分子、语义与实例指标、全局预测及局部案例 | 先交代测试集；0.3 主展示、0.5 补充；配对结果与分布各司其职（R01–R03、S01–S04、F12–F15） |
| 身份匹配与密度引导构建 | 身份能否匹配，配体构象能否准确重建？ | 默认 Match、竞争身份数量、EMERALD-ID、构建对照、精度统计 | 合节；F1 与身份准确率分开；内部消融与原版 PocketXMol 详细比较分流（M01–M08、B03–B04） |
| 大复合物中的自动化应用 | 完整流程在实际复杂对象上交付了什么？ | 现有流程级统计、尝试预算、完整对象的全局和局部结果 | 案例串联定位、身份、构象，不重复方法流程图（E01） |
| 运行时间分析（视证据量独立或并入相关结果） | 各环节与对照的计算成本如何？ | 已有计时、硬件、单位、准备／返回情况 | 计时与匹配任务条件对应；不凭口头“很慢”写定量结论（M07） |

## 第三优先级：主图与补充的分工

先按约六组证据尝试排版：方法总览、Find 定量与全局案例、Match 与 Build 主比较、完整流程应用、运行成本、关键消融。它们是内容分组，不是强制图数；一个科学问题所需面板过多时可拆分，不为凑六张把独立问题挤成一图。[Nature Communications 当前官方页面](https://www.nature.com/ncomms/submit/article) 依篇幅允许最多 10 个主要展示项；导师约六张的意见属于组织建议。（G02）

| 内容 | 正文建议职责 | 补充建议保留 |
|---|---|---|
| 总览与架构 | 输入、真实空间对象、默认流程、结构输出 | 形式化表示、细层架构、接口说明；部分内容归 Methods |
| Find 定量 | 主要阈值、两种受体、关键分布与配对比较 | 0.5 阈值、完整曲线、其余统计 |
| Find 案例 | 全图参考与所有预测候选，加有来源的局部放大 | 提供不同信息的其他案例 |
| Match | 默认模型、身份竞争难度、对照；F1 简短报告 | 四变体、两张雷达图、类别细节、单例肽类交代 |
| Build | 构建对照与必要精度结论 | 原版 PocketXMol 详细比较及更多分层结果；正文保留结论和引用 |
| 流程应用 | 完整对象与关键流程级定量证据 | 额外对象、完整预算曲线与失败情况；作者希望保留的主曲线按信息量决定位置 |

总览图与架构图依次处理：CryoAtom2 来源路径；SMILES 外部输入与分子图转换；不同 blob 与原图位置；site 到 receptor pocket 的来源；模块、运算、特征的统一视觉语法；密度通道的真实来源；默认 Build 和真实结构输出。配色承担科学语义。理想三维构象不能暗示已知参考结合姿态，局部放大不能换成另一案例。（F01–F11、F13）

## 第四优先级：文字、双语和追溯同步

决定与结果结构确定后，先改中文源稿，再同步英文。Overview 简明解释方法；Methods 承接数据构造、严格指标、算法和对照条件；Abstract、Introduction 与 Discussion 围绕最终主张统一。六段录音没有可确认的摘要／引言逐段意见，不能补写成导师指示。（G01、G03）

摘要保留关键能力与证据，条件与数字一致；引言从问题推进到本文实际贡献；讨论综合结果意义、适用范围和下一步问题。已有方法也联合使用受体与密度，创新定位应落在本文实际方法与能力，不宣称首次联合这两种信息。相关原文及官方规范见 [分节评价中的资料表](02_分节建议与评价.md)。

获得实施授权后，图与双语图注回到所属 PPT 维护，面板引用与正文同步；涉及实验数字或图表选择时更新冻结来源、追溯文档与 PPT 批注。需要生成 Word 时才按转换工具说明执行转换与核验。本轮没有运行这些修改与导出步骤。

## 后续实施的验收依据

- 每条改动能回指本轮条目，额外建议明确标注来源；录音未表态处不记成同意。
- 科学单位、输入条件、指标定义、评价分母与冻结计算一致；转补充的结果仍可找到。
- 每张主图回答明确问题，面板提供互补证据；全局与局部、不同案例的对应关系真实。
- 中英文正文、图注和图内标签使用同一术语，结论力度一致；直接证据直接陈述。
- 实施前重新确认来源版本，保留作者手工改动；本轮未把任何建议应用到论文。
