## 解释条目的规则

每项实质建议保留编号、所属章节、录音文件及音频内时间。整理后的导师意思、作者当时回应、资料事实和整理者判断分别呈现。转录摘录不冒充经人工听审的逐字原话；无法确定的词句、说话人和指代保留疑点。重复建议合并时保留各次来源，立场变化按先后次序记录。

作者态度区分明确同意、部分同意、解释、保留、反对和未表态。短应答不能单独证明采纳。优先考虑导师的建议，不以机械比例决定科学内容。

公开文献只用于核查领域事实和提供写法参照。期刊官方要求、已发表论文的具体做法、本地写作技能和整理者的推断不能互相替代。必要实验条件准确表述，直接证据支持的结果直接陈述，不额外堆叠防御性限定。
