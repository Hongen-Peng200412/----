# Stage1 补图间距与作者版本追溯

本轮在作者已批准的 Stage1 补充整理之上, 收紧两张补图的行列空白, 并落实作者版本、颜色版本和退役页面的追溯规则。已有数据、图内内容、双语图注及正文 v1 不变。依据上一轮[执行记录](../stage1_supplementary_20261029/执行记录.md), 本轮独立保存新的作者基线。

末尾 `(v数字)` 表示科学来源不变的作者编辑版, 自动继承去掉后缀的登记与科学重建入口; 手工排版保留在当前可编辑 PPT。`NO_LEVEL` 不参与去后缀。颜色页逐个登记实际旧名来源, 不按 `color` 字符串猜测。五条当前 PPT 中不存在的图名退出活动登记, 将仍被颜色页使用的科学素材与生成来源接入当前名称; 历史可由 Git 查询, 不删旧代码与冻结素材。示意图只记录素材、构造和作者版本来源, 不要求实验统计图专属的分母或指标重算。

两张补图保持 2×3 和 2×2 面板、全部统计点、标签及图例, 仅调整布局间隔。先保存原生可编辑 PPT, 再同步四份补充 Word 的对应图像, 保护其余图文和消融表格。长期代码复用当前独立子目录与原图元运输。追溯的人工维护源仍是八份 `图表追溯.md`, 来源批注同步到 PPT。正式运行命令和门控验收分开记录。

Git 保持作者当前 HEAD 和暂存区, 新改动留在工作区, 不提交。完成一次代码职责与注释自查后, 依先前授权进行限定范围独立审查, 后续只窄查问题。
