## 正式运行命令

本节只记生产入口, 测试和门控另列。最后一次采用作者视觉间隔修订的正式重建命令为:

```powershell
python -X utf8 -B 转换工具/ops/rebuild_figures.py --figure stage1-additional-analysis --figure stage1-no-level-comparison-NO_LEVEL --build-root temp/stage1_layout_provenance_20261030/rebuild_final_visual
python -X utf8 -B temp/stage1_layout_provenance_20261030/merge_ppt.py
python -X utf8 -B temp/stage1_layout_provenance_20261030/render_ppt.py
python -X utf8 -B temp/stage1_layout_provenance_20261030/publish_ppt.py
python -X utf8 -B 转换工具/ops/figure_provenance.py --sync
python -X utf8 -B temp/stage1_layout_provenance_20261030/prepare_words.py --reuse-compiled
python -X utf8 -B temp/stage1_layout_provenance_20261030/publish_words.py
```

完整重建顺序仍是准备统计、Python绘图、原生PPT装配, 旧 temp 被屏蔽, 两个回执均通过。`merge_ppt.py` 只把新形状树接入作者最新文件, 其余ZIP部件不动; 原生 PowerPoint 打开并导出验收后才发布。`--sync` 更新当前图集的来源批注和占位署名, 没有改写冻结历史图集。

四份 Word 使用唯一 `md_to_word.py`／`md_to_word_operation.py` 入口编译临时 `figure_input.md` 的两条正式PPT指令, 实际完整命令位于 `word_prepare_receipt.json`。只将两张新图及图像尺寸／回转元信息接入现有作者 Word, 不发布临时图稿的其他内容。`--reuse-compiled` 只复用本轮相同PPT已生成的图稿编译候选, 不读取其他任务缓存。
