# 总览图的独立组件与可编辑三维场景

总览图分别优化 Build 左侧和 Build 及输出。作者第 1 页历史图与第 2 页 baseline 保留，第 3、4 页分别承载首个左、右方案，其他方案顺次追加；左右组件保持统一的幻灯片坐标框，复制后无需重新缩放。

## 场景与视觉契约

- 图示仍表达 Find 的五个候选、Match 的三个化学身份及一次拒绝、Build 的四个配体结合构象。B1、B2 共用绿色身份，B3 为灰色假阳性，B4 为金黄色身份，B5 为粉色身份。
- 使用紧凑的四位点蛋白作为原子坐标基础。三种真实化学身份的 SMILES、RDKit 游离三维构象和结合构象逐原子一致；游离与结合构象不能仅有刚体位移。
- 密度为坐标生成的示意密度，混合配体占据为示意组装；在图注和来源批注明确说明，不能标记成真实 cryo-EM 数据或一次模型输出。
- 全局密度、受体和配体分别使用浅灰包络、蓝灰 cartoon、元素着色的球棍。密度与受体在 Input 中的投影比例相同，Candidate 与 Ligand poses 使用相同相机、像素画布和 PPT 图片框。
- 优先选自然投影较瘦长且四个位点分开的相机，不进行非等比拉伸。原生会话另外保存更瘦和较展开的备选角度。

## 两组版式

左侧 A 保留紧凑 Input，按共享身份组织 blob，并将 Reject 独立于化学身份框。左侧 B 按 B1–B5 顺序排列 blob，将 SMILES 改为横向输入条以缩短 RDKit 路径。两组使用相同分子、坐标、颜色和相机。

右侧 A 显示密度、完整受体 cartoon 和四个配体。右侧 B 采用原生局部 ribbon 剖切，仅隐藏遮住配体的前景片段，完整原子保留。原生编辑包另保留密度网格表示，不把局部口袋 PNG 拼到整体复合物上。

左侧 C 和右侧 D35/D55/D70 用于透过受体查看 blob 和配体。它们以同一浅灰疏网格显示密度，受体 cartoon 分别为 35%、55%、70% 透明，配体与 blob 保持不透明。左 C 对应 55%，三种右 D 可直接替换；原生会话保留 A/B/C 和三种 D 的全部六个表示。

## 交付与验收

正式 PPT 保留作者手工内容并提供可独立复制的组件，以及一页默认组合预览。ChimeraX 会话打开即为完整全局画面，内嵌地图，不依赖旧 temp。详细教程覆盖透明度、模型显隐、整体角度、单个配体移动与旋转、恢复、保存、同一相机导出和 PPT 替换。
